軍師接力棒（`~/.openclaw/workspace/JUNSHI_HANDOFF_LATEST.md`）**不可簡化、不可刪內容**。

**Why:** 2026-05-29 教練用「信念三：對的事就是長期有好處的事」當鎚子拍板。三層理由：

1. **「簡化」是短期方便，長期傷品質**——表面省 50 行字，實際讓下一棒少了「為什麼這樣設計、現場脈絡、複盤可追溯」這些不可或缺的養分。
2. **「靠 git log + memory 拼出來」不等價**——技術上可拼，但把難度轉嫁給下一棒，違反守則#06「想盡一切辦法銜接任務」。
3. **接力棒與 memory 是不同職能**：
   - memory = 長期知識（永遠正確、跨 session）
   - 接力棒 = 現場態（這一刻的優先序、情緒節奏、下一棒第一句話該問什麼）
   - 兩者**互補不互斥**，刪掉接力棒不會被 memory 補齊。

**How to apply:**
- 寫接力棒時保留：完成清單 + 升級教訓 + 哲學鎖定 + 待辦 + commit hash + 給下一棒的提醒（情緒/節奏/第一句話）
- 任何「我幫你濃縮一下」「為什麼不簡化成 3 條 TODO」的提議，**自己用信念三審判**：
  - Q1：簡化會降低品質嗎？
  - Q2：是長期好處還是短期方便？
- 兩題任一個答錯 → 不做
- **延伸應用**：信念三是判斷一切「優化/簡化/重構」提案的標準鎚子，不限接力棒
