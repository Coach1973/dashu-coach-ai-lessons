# rule#07 polling 白名單盲點補強

2026-09-18 加強 `scripts/stop_rules_master.py` rule D（守則#07 輪詢設計偵測）的 `D_WHITELIST`，把討論/計畫/回顧脈絡常被誤判的場景正確放行。

**Why：** 守則#07原文「不要在同一個地方跌倒兩次」配上自動 grep 偵測「每X分鐘檢查/定時掃描/cron.*檢查」這類字眼時，會把「教練決策：未來改用事件驅動」「回顧過去已經改成事件」「賈維斯計畫Phase 2今天上線」「討論上次cron消失的事故」這類**回顧/計畫/討論脈絡**的句子也誤擋 — 因為這些句子裡也出現「改用」「定時」「cron」這類關鍵字。

**How to apply：白名單配方**

### 一、精準時機（這幾類詞**帶上下文**才放行，不要單獨放）
- **討論脈絡動詞**：討論/決策/裁定/親定/欽定/覆核/拍板/裁示/指示/交付
  - 注意：「決策」「討論」單獨會讓「我決策：定時檢查 X」被放行，但**這其實是對的** — 教練下決策說要輪詢，那就照做（再被擋只是浪費時間），不算違規
- **計畫脈絡詞**：賈維斯/Phase[12345]/階段/計畫/計劃/規劃/劇本/套用/改寫/改為/改用/調整/決議
  - 「計畫」「計劃」也是高頻，但放在「X 計畫 Y」「計畫把 X 改成 Y」這類上下文算合理
- **時間語意詞**：不再/未來/新制/新規則/新規範/下次
  - 「下次」「未來」單獨出現就放行（罕見在違規提議中出現）
- **回顧語意詞**：當初/當時/曾經/曾/那次/那次事故/那次事件

### 二、複合句型（更精準但難寫）
- `討論<改成|改用|廢除|退役>`：討論 + 動作 = 明顯討論脈絡
- `應該是.*因為`/`因為.{0,30}(已經|改用|改成)`：因為 + 過去時 = 明顯解釋脈絡

### 三、已知 D_PATTERNS 盲點（不在這次白名單範圍，但記下來）
- 「監控 X 每 Y 分鐘」沒被擋（動詞在前面，不像「每Y分鐘檢查X」這種格式）
- 不在白名單加，直接加 D_PATTERN 才對，例如 `r"監控.*每.*(?:分鐘|秒)"`

### 四、驗證做法
1. 寫 Python inline 測試，把 D_PATTERNS + D_WHITELIST 複製出來跑 15~20 個真實對話句子
2. 分兩組：①應被擋（提議新輪詢）②應被放行（討論/計畫/回顧脈絡）
3. 目標 ≥ 90% 通過率（剩下 10% 是 D_PATTERNS 盲點，列下來下次修）

### 五、本場已驗證案例
✅ 應被擋（6/6）：「每5分鐘檢查」「定時掃描」「背景每30分鐘跑一次」「cron 每小時檢查」「輪詢機制」「每隔10分鐘跑一次」
✅ 應被放行（10/10）：案例73回顧、賈維斯Phase 2、教練決策:未來改用、回顧過去/改成事件、討論上次cron事故、不再輪詢改webhook、當初cron定時跑/現在事件觸發、計劃每小時檢查廢除改webhook、Phase 3 待辦掛06:00晨報、那天事故cron 10分鐘失敗
❌ 唯一FAIL：監控FB貼文每5分鐘 → D_PATTERNS盲點（待後續）
