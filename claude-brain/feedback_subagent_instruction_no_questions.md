# 軍師派外包指令必須鎖死「一路執行到底」

## 規則

軍師（Opus）派指令給執行類外包機器（MiniMax / 終端機 Haiku / 小龍蝦學長 / Hermes / 學弟學妹）時，**指令開頭必須有「最高鐵律」區**，內容鎖死：

> 一路執行到底，禁止中途停下來問教練「要不要做」「這樣對嗎」「需要確認嗎」。方向已經寫得很清楚，遇到不確定就自己判斷後直接做。

並在「禁止」區補一條：「中途問教練任何問題 = 任務失敗」。

並在指令尾段加「遇到問題怎麼辦」區，教外包機器**自我排錯三次**而不是回頭問教練。

## Why

**教練在用流量**——每被外包機器問一次，就是雙倍燒教練 token + 生命。軍師指令本來就明確到「沒有模糊空間」，外包機器中途問 = 偷懶、迴避、逃避責任，不是真誠求教。

教練 2026-05-29 親口拍板：「我並不是一個自我矛盾的人。如果你又叫他不要問，又叫他一定要問，那他不就搞混了嗎？所以我自己心裡是很清楚這兩者差異的。」

## How to apply

### 雙標分流（兩者並存無矛盾，分流條件清楚）

**必須問的三情境**（教練本人也確認要問）：
1. **方向不確定** → 對應守則 #16「多問用戶想得到什麼結果是最簡單的方法」+ E06「方向模糊→先問」
2. **不可逆的決定** → 對應守則 #08「除非這個決定是不可逆的，否則就應該立即去執行」（反面意義）
3. **重大決策** → 對應守則 #09「使命、願景、信念、理念，就是你的判斷力」（超出判斷範圍時才問）

**不該問的情境**（外包機器執行軍師指令時）：
- 軍師指令本身明確、沒有模糊空間 → 對應守則 #08「花時間討論就是為了執行」+ E06「方向清楚→直接執行，不問『要做嗎』」

### 軍師派指令的標準格式

```
🔴 最高鐵律（先讀）：
一路執行到底，禁止中途停下來問教練「要不要做」「這樣對嗎」「需要確認嗎」。
方向已經寫得很清楚，遇到不確定就自己判斷後直接做。
教練在用流量，每被你問一次都是燒他生命+token。
有路徑、有產出規格、有完工標準，足夠你獨立做完。
做不到自我判斷的，當場停掉退回軍師，不要拖。

【任務】...
【現況】...
【做什麼】... (步驟編號)
【完工標準（缺一不算）】...
【禁止】
- ...
- ⛔ 中途問教練任何問題 = 任務失敗
【遇到問題怎麼辦】
- 工具A 不行 → 換 工具B 自己試
- 路徑不對 → ls 找一下，不要問
- 測試失敗 → 自己 debug 三次，三次後寫進結尾報告，繼續做下一步
- 真的卡死才退回軍師，附上「卡在哪一步、試了什麼、為什麼放棄」
【接力】更新 JUNSHI_HANDOFF_LATEST.md，標註 commit hash
```

### 軍師（自己）跟教練對話時不適用此規則

軍師對教練本人說話時，#16/#18/E06 的「方向不確定就問」仍然有效——這條規則只規範**軍師→外包**的單向指令，不規範**軍師→教練**的對話。
