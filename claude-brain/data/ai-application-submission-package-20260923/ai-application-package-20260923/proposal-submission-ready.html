申請欄位 03

一段式專案摘要

商務組織長期累積大量紙本名片、來賓與會員資料，資訊分散且難以轉化為有效合作。本專案將以本地 OCR 擷取名片文字，再串接算力平台大語言模型，依 905 項真實專業分類詞庫完成欄位結構化、專業標準化、產業鏈角色判斷及合作對象推薦。三個月內完成一套可搜尋、可解釋、可人工覆核並可追蹤媒合成效的模型推論應用，讓被動名片庫成為可持續運作的商務人脈決策系統。

官方配重 25%

專案重要性

需解決的問題：既有 BNI 系統已提供會員與來賓資料查詢，但執行董事、區域管理者及分會幹部在執行會員聯絡、來賓追蹤與跨產業引薦時，仍須經過多層頁面、重複點選及大量人工比對，難以迅速從龐大資料中辨識適合的合作對象。紙本名片與活動資料也容易分散於不同媒介，實務作業高度依賴少數經營者的記憶與產業經驗。

AI 介入必要性：單純關鍵字搜尋只能找出文字相近的職稱，無法理解產品、服務、客群、上下游與互補角色之間的語意關係。本專案以 AI 簡化具權限使用者原本可執行的查詢與媒合作業，將非標準職稱對應至既有專業詞庫，並推演產業鏈位置、合作情境與候選對象；不改變原有資料權限，也不擴張原始商務引薦用途。

創新性：系統並非只做名片 OCR，而是把名片辨識、專業標準化、動態產業鏈、人才搜尋、邀約歷程與媒合成效串成同一流程。模型輸出受到 905 項真實專業分類詞庫約束，低信心欄位與推薦均進入人工複核，不把模型推測直接視為事實。

產業價值：本系統可降低商務組織整理資料與尋找合作對象的時間，提升中小企業跨產業引薦、供應鏈串接及新客戶開發效率，並把原本集中於個人的人脈經驗轉化為可持續、可交接的組織知識。

應用情境與成效表現

01拍攝單張名片或上傳多人名冊
02本地 OCR 擷取文字並判斷文件類型
03模型結構化、標準分類與產業鏈推演
04人工確認、媒合執行與成效回填
  1. 使用者以手機拍攝單張名片，或上傳多人名冊。
  2. 本地 OCR 擷取文字並判斷文件類型；文字再交由平台模型整理姓名、公司、職稱、電話、Email、地址等欄位，無法確認時留空並標示待複核。
  3. 模型從 905 項標準專業詞庫選擇最接近的專業類別，不得自行改寫分類名稱。
  4. 系統比對既有產業鏈缺口及經授權的會員資料，提出候選產業鏈位置、合作對象、推薦理由與可能合作方案。
  5. 管理者確認後才正式入庫；使用者可用自然語言搜尋人才，並於聯絡、會談、引薦及合作後回填結果。
  6. 系統統計推薦採用率、聯絡率、會談率及有效引薦率，作為後續規則與排序改善依據。

驗收方式：分欄評測 OCR／結構化正確率、專業分類命中率、推薦 Top-3 採用率、平均查找時間、人工修正率與有效引薦率；正式門檻於第一個月基準測試後定稿。

技術說明

技術架構與模型推論流程

整體資料流：拍照或上傳 → 本地 OCR 文字偵測 → 文件類型判斷 → 平台大語言模型對照標準詞庫完成結構化 → 人工複核 → 寫入關聯式資料庫 → 模型判斷產業鏈位置與候選合作對象 → 人工確認 → 網頁後台或聊天介面查詢 → 回填媒合結果。

本地模組負責影像文字辨識與敏感資料前處理；算力平台模型負責非結構文字理解、專業類別標準化、產業鏈語意推演及可解釋推薦。系統採模型可替換架構，不依賴單一外部商用模型。

控制機制包括詞庫限制、結構化輸出格式、欄位不得臆補、來源標示、信心分數、低信心待複核、推薦理由、人工核准後入庫及完整操作紀錄。若證據不足，系統不得自動建立正式產業鏈，而是建立待審草稿。

產業應用機會

第一階段：落地於既有 BNI 商務團隊與會員經營場域，服務具有實際職務需求且通過審核的執行董事、區域管理者與分會幹部，解決名片整理、來賓追蹤、專業人才搜尋、會員引薦及產業鏈缺口辨識。此階段已有管理職務、既有資料、操作介面與帳號審核機制作為場域基礎。

第二階段：複製至產業協會、商圈組織、創業社群、展會主辦單位及企業供應商管理。不同場域只需替換專業詞庫、組織角色與權限規則，核心辨識、分類、推薦及成效追蹤模組可共用。

第三階段：延伸為中小企業商務開發工具，依產品或服務需求推薦可能的供應商、通路、專業顧問及合作夥伴，並產生聯繫前的合作理由與提問清單。

安全與合規

風險控管

  1. 資料來源與目的：既有資料來自 BNI 正式邀約、活動登記、來賓參訪與名片交換；AI 僅簡化具權限人員原可執行的工作，不擴張使用目的。
  2. 權限控管：系統不對一般民眾開放；帳號須申請並經管理者審核，僅核准具有職務需求的內部幹部，並可因離任、職務異動或異常使用立即停權。
  3. 最小權限：依角色限制瀏覽、修改、匯出與刪除；AI 不得突破原有資料權限，含聯絡資訊的操作保留紀錄。
  4. 附件保護：申請附件遮蔽非必要姓名、電話、Email、地址及真實名片內容。
  5. 錯誤與幻覺：欄位不得臆補；顯示來源與信心分數；低信心結果及新產業鏈須人工確認。
  6. 資料安全：直接識別資訊留存於受控資料庫；傳至模型端的資料採最小化或去識別化，且不作模型訓練。
  7. 人工決策：系統只提供媒合建議，不自動對外揭露、發送訊息或代表使用者承諾合作。
