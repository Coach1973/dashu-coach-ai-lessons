# 大樹教練角色鎖臉 SOP（Gemini / 通用 AI 版本）

> 用途：教練把這份 prompt 貼到 Gemini（或 ChatGPT、Claude.ai 等對話型 AI），
> 加上 5 張教練本人照片，就能生成「臉像教練本人」的漫畫/插畫。
> 不用任何 API、不用任何技術背景，純對話框操作。

---

## 📸 步驟一：先準備這 5 張照片（您 LINE 相簿裡的）

1. 打開 LINE → 相簿 → 找「大樹新形象照」「去背形象照」
2. 依序下載/轉發這 5 張到電腦或手機：
   - **`LINE_ALBUM___260711_7.jpg`** ← 主參考（最重要）
   - **`LINE_ALBUM___260711_4.jpg`** ← 近距離五官
   - **`LINE_ALBUM___260711_9.jpg`** ← 側面輪廓
   - **`LINE_ALBUM___260711_6.jpg`** ← 自然笑容
   - **`LINE_ALBUM___260711_8.jpg`** ← 嚴肅神情
3. 確認檔案沒被壓縮到模糊（最好每張 > 100KB）

---

## 💬 步驟二：開 Gemini 對話，上傳照片

1. 開 Gemini App 或 https://aistudio.google.com/
2. 開新對話
3. 點附件圖示 📎 → 上傳剛才那 5 張照片（5 張都要上傳）
4. 把下方「步驟三的完整 prompt」整段複製貼到對話框，按 Enter

> ⚠️ **關鍵**：照片一定要先上傳再貼 prompt。AI 看到照片才知道「要鎖這張臉」。

---

## 📝 步驟三：完整 Prompt（複製整段貼上）

```
你是一位專業的傳統水墨水彩漫畫插畫家，請幫我畫一張漫畫風格的圖。
我上傳了 5 張我的照片，請務必以下列規則處理臉部：

【鎖臉規則 — 最重要，違反此規則就重來】
- 以上傳的 5 張照片為「唯一且絕對」的臉部參考
- 禁止使用任何 AI 庫存臉、模板臉、商務亞洲男性通用臉
- 保留我可辨識的真實長相，不做任何風格化改變
- 水墨水彩質感只用在場景與衣服，臉部保持寫實

【角色設定】
- 姓名：大樹教練（Coach Dashu）
- 國籍：台灣人
- 性別：男
- 年齡：40 歲出頭，視覺上看起來年輕有活力，不要顯老
- 身形：精瘦、中高
- 臉型：偏窄的橢圓到長方臉，下顎線條柔和（不是寬方臉）
- 額頭：略高
- 髮型：純黑色短髮，側分貼順，無白髮、無灰髮、無銀髮、無白鬢角
- 眼睛：杏仁形深色眼睛，單眼皮或內雙，上眼皮略內收
- 鼻型：直鼻樑，鼻尖柔和
- 嘴唇：上唇較薄、下唇稍飽滿
- 膚色：暖黃偏小麥色，不要變白

【固定造型】
- 灰色格紋三件式西裝（西裝外套 + 背心 + 長褲）
- 白色襯衫
- 藍色細點領帶
- 無眼鏡、無鬍鬚、無名牌、無胸針、無袋巾
- 表情：沉穩、銳利、不怒自威的「台灣金牌教練」氣質

【禁止偏移】
- 不要寬方臉、不要圓臉、不要過度壯碩
- 不要灰髮、白髮、銀髮、白鬢角
- 不要用庫存臉替代我
- 不要把水墨風格化套到五官而改變我的辨識度

【場景描述】
（這裡貼您的場景，例如：）
超廣角構圖。大樹教練獨自站在夜晚的黑色海岸線上，身後是一道由 AI 電路、手機圖示、資料流交織而成的巨大發光浪潮。他站姿穩定，沒有逃跑。遠處有許多小小的人影在水中掙扎，而他正在研究浪頭，準備向前。氛圍：無可避免的科技大浪、重力感、覺醒。

【畫面規格】
- 16:9 寬螢幕
- 傳統中國水墨水彩風格，電影感寫實，戲劇性編輯構圖
- 豐富層次的筆觸紋理，淡淡的宣紙質感
- 表情光影，成熟商業故事敘事

【護欄後綴 — 一定不要漏】
畫面中：
- 不要任何可讀的文字、不要中文字、不要英文字
- 不要 logo、不要浮水印、不要胸章、不要名牌
- 不要對話框、不要說話框
- 不要白髮、不要灰髮、不要銀髮
- 不要多餘手指、不要扭曲的手
- 不要第二個人物（除非場景描述明確要求）
- 不要寬下顎、不要圓臉、不要鬍子、不要八字鬍
- 不要庫存臉、不要西方臉

請開始畫。
```

## 🔄 步驟四：對 Gemini 的輸出做驗證

1. 看生成圖，檢查：
   - 臉像不像您本人（最重要）
   - 髮色是不是純黑、無白髮
   - 服裝是不是灰格紋西裝 + 白襯衫 + 藍點領帶
   - 場景是不是您要的畫面
2. 如果不像：換一張主參考照片（`LINE_ALBUM___260711_7.jpg` 最重要，這張是主錨點）
3. 如果您想鎖臉更緊：再加一句「**嚴格遵守：臉部五官位置、間距、形狀要跟我照片完全一致，視覺年齡 38-42 歲**」

---

## ⚙️ 不同 AI 的小調整

| AI 平台 | 上傳方式 | Prompt 需不需要改 |
|--------|---------|-----------------|
| **Gemini 2.0 Flash** | 點附件圖示 → 多選上傳 | 不用改，直接貼 |
| **ChatGPT (GPT-4o)** | 對話框拖曳圖片 | 不用改，直接貼 |
| **Claude.ai** | 對話框拖曳圖片 | 不用改，直接貼 |
| **Midjourney** | 上傳 → 拿圖片 URL → 用 `/imagine URL prompt` | prompt 開頭要加 `--cref <URL>`，其餘照貼 |
| **DALL-E 3**（OpenAI API） | 透過 API 帶 image | 這份 prompt 文字部分照用，技術細節交給程式 |

## 🔁 改場景不用重傳照片

每張漫畫的 prompt 只有「**【場景描述】**」那個區塊會變，
其他「**鎖臉規則 / 角色設定 / 固定造型 / 禁止偏移 / 畫面規格 / 護欄後綴**」都不用動。

要畫下一張時，只要換「**【場景描述】**」那段就好，照片不用重傳。
