## How to apply
1. 聽到「桌面版」→ 腦中立刻替換為 GUI，**不要再想「是不是純聊天版」「能不能跑 shell」**——能！跟 CLI 工具能力相同甚至更強
2. 聽到「終端機」→ 立刻替換為 CLI，就是黑底文字介面
3. 聽到「Claude 桌面版」「Windows 桌面版 Claude」→ 就是 Claude Code 的 GUI 版本，能 Bash、能 Read/Edit/Write、能 git push、能跑 PowerShell
4. 兩者共用 `~/.claude/projects/.../jsonl` 對話記錄、共用 CLAUDE.md 燒錄、CC Switch 同步控制
5. CLI 中打 `/desktop` 可直接切到 GUI
