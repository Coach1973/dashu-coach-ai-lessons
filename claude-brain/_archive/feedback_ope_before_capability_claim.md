**禁止憑印象斷言任何外部 API、SaaS、CLI 工具的能力範圍。先 WebSearch + WebFetch 查官網文件，再回答「能/不能」。**

**Why:** 2026-05-17 教練問 NVIDIA NIM Key 能否取代 OpenAI 做 Whisper 語音轉文字，我憑舊印象回答「NVIDIA NIM 只接 LLM、不能做語音」，導致教練糾正：NVIDIA NIM 上有 Parakeet/Canary/Whisper 完整語音堆疊，端點甚至跟 OpenAI 一樣。違反三大信念第二條 OPE「先上網搜」，也違反守則15「說不知道比胡說值得尊重」。

**How to apply:** 每當要說「X 工具不能做 Y」「Z API 沒有這個功能」「這個 SDK 限制是…」前，第一動作是 WebSearch 該產品官網文件，第二動作 WebFetch 確認頁面實際能力。產品能力更新很快，舊知識在新時代就是錯的。
