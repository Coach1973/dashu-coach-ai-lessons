## Why（教練拍板背景）

5/19 終端機 Claude 上網查驗 4.15 → 5.12 升級風險，找到三條對教練體系致命的開放中 issue：
- **#81710** heartbeat 跟 `/new` `/reset` 不再讀 SOUL.md / agent.md / identity.md（regression from 5.7）
- **#80613** dreaming pipeline 污染中文 MEMORY.md
- **#82070** 升 5.12 後 CLI 冷啟動慢 14 秒

教練判斷：對的事就是長期有好處的事，穩定中發展優於冒險升級。

## How to apply

- 教練說「VPS 更新」→ 仍照 SOP 升 VPS（VPS 升級風險小）
- 教練說「本機升級」「Mac 升級」「openclaw 升級」（無 VPS 字樣）→ 提醒戰略決議是本季不升，要升先重新評估三條 issue 是否已修
- 未來定期檢查：每月看一次 openclaw GitHub release notes，#81710 #80613 #82070 修掉後再向教練建議
