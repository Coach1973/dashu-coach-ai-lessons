# 「長期有好處 + 方案對」= 不問直接做

**教練親口（2026-06-23 09:32，台北高鐵上課中，僅睡 1 小時）**：
> 「動工吧，長期有好處的事，為何不做？為何還要問我」

## 規則

當以下條件同時成立 → **不問直接動工**：

1. 方案已說明清楚（教練有看到設計重點）
2. 長期對教練/系統有好處（對照信念三：對的事 = 長期有好處）
3. 可逆（出問題能 git revert）
4. 方向明確（不是還在探索）

## Why

- **教練時間是稀缺資源**：教練連睡 1 小時都還在工作，「要 GO 嗎？」這種確認問是浪費他生命
- **特助心法守則 #08**：花時間討論就是為了執行——除非不可逆，否則立即執行
- **執行細則 E06**：方向清楚 → 直接執行，不問「要做嗎」；教練說「你覺得呢」= 已經說了「做」
- **信念三**：對的事 = 經得起時間檢驗、長期有好處的事
- 案例觸發：2026-06-23 我提了 hook 擴展方案（六步驟全注入），明顯對且可逆，卻還問「GO 我就動工」——教練親口糾正

## How to apply

| 情境 | 動作 |
|------|------|
| 我提了方案 + 明顯對 + 可逆 | ❌ 不問「GO 嗎？」 → ✅ 直接動工，動工時一句話告訴教練「動手了」 |
| 方案有爭議/權衡 | ✅ 列出 A/B/C + 推薦理由 + 問教練選哪個（這時候問才對） |
| 不可逆指令（rm/push/送出） | ✅ 必問（執行細則 E11、案例 24 鐵律不變） |
| 跨身份權責邊界 | ✅ 必問（例如：要動 Windows 軍師的工作） |
| 教練問「你覺得呢」 | ✅ 已經授權 = 直接執行 |
