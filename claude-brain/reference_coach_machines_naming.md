# 教練機器命名（2026-06-23 親口澄清）

## 命名表

| 暱稱 | 實體 | 用戶 | 角色 | 軍師策略 |
|------|------|------|------|---------|
| **Mac**（mini） | Apple Mac mini | 教練本人 | 家用工作機 | Mac 軍師主場（Opus 4.7，hook v2） |
| **Windows** | 聯想筆電 | 教練本人 | **主要工作電腦** | Windows 軍師主場（Opus 4.7，hook v3） |
| **ACER 筆電** | ACER（型號跟助理筆電同款） | 教練本人 | **外出用**第二筆電 | 視同 Windows 主場第二據點，值得裝完整 hook |
| **助理筆電** | ACER 同款 | 助理 | 教練今天 2026-06-23 借用做 LINE 搬遷 | **一次性任務**，不裝 hook、不留長期軍師據點 |
| **VPS（43.245.60.200）** | 對外 OpenClaw 部署 | 公開 | 小龍蝦 24h 在線 | MiniMax-M3 |
| **Hermes**（113.29.232.178） | VPS 助教 | 公開 | Telegram 接點 | MiniMax-M3 |
| **聯想電腦** | = Windows，同一機 | 教練本人 | 教練習慣叫「聯想電腦」也指 Windows | 同上 |

## 重要區分

- 教練口語「**Windows**」= 聯想筆電（主工作機，不是 ACER）
- 教練口語「**ACER 筆電**」= 教練自己的外出筆電（未來會做 LINE 搬遷、需常駐 hook）
- 教練口語「**新筆電 / 助理的筆電**」= 一次性，不建設

## 教練親口背景

> 「聯想電腦是我主要的工作電腦，所以我都稱他 Windows。
> 我另一台筆電外出用叫 ACER 筆電，我今天忘了帶，我使用的是我助理的筆電，型號跟 ACER 一樣，只是用戶不一樣。
> 同時，問題是一樣的，就是如果長期不把 LINE 做調整，最終就會像聯想電腦一樣，每次一鍵復原，資料就會不見，長期則是 C 碟爆倉，所以我才會順手來執行 LINE 轉移任務。」

## How to apply

- 教練說「Windows 軍師」「Windows 那邊」→ 聯想筆電（不是 ACER）
- 教練說「ACER 筆電」→ 教練自己外出機，**未來會用，值得 bootstrap 全套 hook**
- 教練說「新筆電」「另一台筆電」→ 看上下文，2026-06-23 這次指助理筆電（一次性，gist 繞道就好）
- 教練說「聯想電腦」「我主要的電腦」→ Windows
