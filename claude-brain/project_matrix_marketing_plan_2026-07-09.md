2026-07-09，教練提出構想：以「大樹小講」網站為內容創作中樞（中央廚房／司令部），教練只需在此發布一場活動或一張EDM，AI就自動同步發布到FB（個人頁+粉絲頁）、IG、LINE、乾淨世界，未來可擴充Dcard、Threads；語音檔案則同步更新到Podcast。教練明確表示**不急著馬上執行**，這是「長期有益、遲早要做」的方向，先記錄規劃即可。

**AI 查證後的評估結論（2026-07-09，WebSearch實測）**：

| 管道 | 能否全自動 | 關鍵限制 |
|---|---|---|
| FB粉絲專頁 | 可以 | 需申請開發權限，平台審核2-4週 |
| FB個人首頁 | 不行 | Facebook自2018年起技術封死，任何工具都無法自動發，只能手動分享 |
| IG（商業帳號） | 可以 | 需轉商業/創作者帳號並綁定FB粉專，同樣要審核；一天上限100則 |
| LINE官方帳號 | 可以，且最快 | 教練現有LINE官方帳號只差開通「訊息推播」功能，不用審核 |
| Threads | 可以 | 2024年底才開放，目前只能立即發，無原生排程功能 |
| 乾淨世界 | 不行 | 官方沒開放外部發文的API，只能人工上傳 |
| Dcard | 不行 | 只有讀取用的非官方API，沒有官方發文管道；用機器人模擬點擊發文有帳號被封風險，不建議 |
| Podcast | 可以，但不是我們開發 | 用Firstory這類平台上傳一次，蘋果/Spotify/KKBOX會自動同步，是平台原生功能 |

**建議的分階段順序（尚未開始執行）**：
1. 第一階段：LINE自動推播（最快、教練現成帳號已有、轉換率最高）+ 幫乾淨世界/Dcard自動生成「一鍵複製」文案包
2. 第二階段：FB粉專 + IG 自動發布（同步等待平台審核期間準備）
3. 第三階段：加入Threads，Podcast流程固定成教練習慣動作

**How to apply**：教練近期忙碌，不主動催進度；等教練說「開始做第一階段」或類似指示才動手申請FB/IG開發權限、開通LINE推播功能。這份規劃是方向定案，具體執行時間看教練心情跟空檔。
