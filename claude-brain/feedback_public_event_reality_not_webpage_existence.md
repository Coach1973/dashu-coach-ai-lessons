# 判斷活動真實性的正確邏輯（2026-07-06 教練親口糾正）

**規則**：一場公開舉辦、有很多人參加的活動，不需要網頁佐證就是真的辦過了——教練不是每一場活動都會做網頁。查不到網頁只代表「沒做網頁」，不代表「不確定有沒有辦過」。

**教練原話**：
> 「不是每一場活動我都會有網頁留存，所以不要以網頁有沒有留存作為判斷活動是否辦過的依據。教練告訴你的，必定是公開舉辦過的，因為一場公開活動有這麼多人參加，這種事情是瞞不住的，只是我不見得每一場都會製作網頁。」

**背景**：軍師幫教練整理「過往講座歷史紀錄」頁面時，把查不到GitHub網頁的場次（嘉義場、新營場）用「查無留存」「gap-note：老實說沒查到...如果您記得細節請補充」這種帶疑問語氣的方式呈現，暗示這些場次的真實性/細節需要教練「證明」。教練直接點出這個邏輯錯誤：他親口說出來的場次，本身就是證據（公開活動瞞不住），不需要額外的網頁佐證才算數。

**How to apply**：
1. 教練親口提供的歷史事實（活動辦過、日期、主題）**直接當作已確認的事實記錄**，不要用「查無資料/未留存/待確認」這種暗示存疑的字眼。
2. 「有沒有網頁」只是一個中性的補充資訊（有網頁的話附連結，沒有就寫「未另外製作網頁」），跟「這件事是否發生過」是兩個完全不相關的維度，不要混為一談。
3. 這條原則的守則對照：#03（思考就是問問題，但問完教練給的答案就該當真）+ #13（客戶的聲音就是存在價值——教練說的話本身就是一手證據，不需要二手佐證）。
4. 適用範圍不限於這次的講座歷史紀錄，任何「教練說他做過/去過/辦過某件事」的場景，都直接採信並記錄，不要因為找不到數位痕跡就打問號。
