# 系統健康檢查（2026-10-16 建立）

起因：10/16 一天內連出三件「默默壞掉」——開機設定檔被清理軟體刪掉、workspace 被拉錯分支換掉（教練指令被擋 3.5 小時）、52 筆自動暫存沒人取回。教練問「真的一切都正常了嗎？」，這支技能把當天手動查過的每一項變成一個指令。

## 步驟

1. 跑：`python3 ~/.openclaw/workspace/scripts/system_health_check.py`（約 30～90 秒；只想快速看不測網站加 `--quick`）。只讀不改。
2. 每一行 ⚠️ **先親自驗證再講**——檢查程式本身也會誤報（10/16 第一次跑就誤報 3 項：中文檔名算錯、網址抓到程式碼、20 分鐘前已修好的舊失敗）。用另一種方法再查一次（例如 `git status` 數刪除、curl 那個網址），確定是真的才算。
3. 真的有問題 → AI 自己能修的就修（照「故障診斷法」：先找同類正常的對照組、修完再跑一次這支確認 ✅），修好才回報。
4. 回報教練 3～5 行白話：總結一句（全部正常／幾項要處理）＋修了什麼＋證據（commit hash）。不要貼整份輸出，不講英文術語。

## 每一項在查什麼（教練問的時候用白話解釋）

| 項目 | 白話 |
|---|---|
| 兩個主資料夾 | workspace（分支 main）與 ~/.openclaw（分支 master）檔案齊全、沒有卡在半路、跟 GitHub 同步 |
| 檢查程式 | 教練每說一句話會先跑的 17 支程式都在，而且沒有任何一支會擋住教練 |
| 自動服務 | 38 個網站／小龍蝦服務都在跑、登出或重開機後會自己回來、都有守門員保護 |
| 網站 | 13 個主站＋作品一覽裡所有 bymyway 網頁都打得開 |
| 網站專案 | ~/github_repos 每個專案沒卡住、沒忘了推 |
| 自動暫存 | 自動同步沒有又把改動「放不回去」 |
| 接力棒鏡像 | 新對話框讀得到最新一棒 |
| 背景排程 | 每分鐘心跳正常、最近 20 分鐘沒有失敗 |
