# 收工總結（執行細則 N9）

教練說總結＝他即將開新對話框。直接做，不問。

## 步驟

1. **先跑一次快速健康檢查**：`python3 ~/.openclaw/workspace/scripts/system_health_check.py --quick`。有 ⚠️ 先驗證、能修就修，寫進這一棒。
2. **濃縮本場 300～500 字**：做了什麼（附 commit hash）、卡在哪、下一步。只寫結果，不寫過程報告（守則 #14）。時間一律台灣時間。
3. **更新接力棒** `~/.openclaw/workspace/JUNSHI_HANDOFF_LATEST.md`：
   - 新的一棒放最上面，**標題一定要有「給跨對話框軍師讀的總結摘要」這幾個字**（鏡像程式靠它認出這是正常的一棒，沒有的話新對話框讀不到；10/16 有人在最上面加「本場追加」，鏡像就停了 4 小時）。
   - 標題格式照舊：`## 🔴 給跨對話框軍師讀的總結摘要（日期 時間 台灣時間，機器＋介面，模型；本段起訖，對話容量約 N%）`，接著「主軸」「教練原話線索」「📋 下一場開工先做」。
   - 只留最新 1～2 棒＋三區待辦（🙋要教練決定／🤫等教練自己提起／🔧AI 自己的清單）；更早的整段搬進 `handoff_archive/`（封存不是刪除）；教練裁示過的待辦當場移出。
4. **記憶**：照 N8 六種情況判斷（指令失敗、教練糾正、要求不存在的功能、外部服務失敗、規則過時衝突、發現更好方法），命中才寫；寫前檢查有沒有密碼／金鑰；寫完把一行索引加進 `claude-brain/MEMORY.md`。同類錯第二次出現→改機制，不加記憶。
5. **commit＋push**（在 `~/.openclaw/workspace`，分支是 **main**，先 `git branch --show-current` 確認，不憑印象）：`git add <這次的檔> && git commit -m "[Mac] 總結：…" && git push origin main`，回報 hash。
6. **回報教練不超過 5 行**：第一句固定說「總結已完成（commit hash），可以開新的對話框。」，再一句主軸＋下一步。**口令默契（教練 2026-10-17 02:03 定）：只有說「總結已完成」才代表總結好了；沒總結完，不准說「可以開新的對話框」。**

## 注意
- 「開工」臨時 worktree 對話框裡，Edit／Write 改不了 `~/.openclaw/**` 正式檔案（會被擋）→ 先寫到暫存區，再用終端機複製過去。
- 跑完之後的 Stop hook 會自動推送；看到「自動暫存放不回去」已會自動逐檔放回（`scripts/safe_stash_restore.py`），不用手動處理。
