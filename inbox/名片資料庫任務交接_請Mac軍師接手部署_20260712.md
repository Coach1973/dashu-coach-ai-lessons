## 📋 請Mac軍師依序執行

1. 確認 Amber 私有雲「名片媒合中心」資料夾能透過 SMB 存取（`smb://amber-Coach`，
   通常掛載後在 `/Volumes/home/名片媒合中心`，實際路徑用 `ls /Volumes/` 確認）
2. `cd namecard-db && pip install -r requirements.txt`（需要 Python 3.10+）
3. 設定 `ANTHROPIC_API_KEY`（教練的金鑰）跟 `NAMECARD_FOLDER` 環境變數
4. **先小量測試**：資料夾裡放10~20張名片，跑 `python watch_and_extract.py --once`，
   開 `python app.py` 看 `http://localhost:5000` 檢查辨識品質（尤其LINE ID、地址），
   沒問題再處理全部
5. 全量：`watch_and_extract.py --once` → `match.py` → `app.py`
6. **設定背景常駐（教練要的「丟了就自動跑」）**：資料夾裡已經有
   `com.coach.namecard-watch.plist.template`，照 README 步驟6把四個佔位值填好、
   `launchctl load` 起來，之後教練丟名片進資料夾，60秒內自動處理，不需要人工介入
7. 接上手機查詢：比照現有 cloudflared（LINE那條通道）的做法，新增一條路由指到
   `localhost:5000`，讓教練出門用手機也能查
8. 跑完之後麻煩更新 `claude-brain/project_namecard_db_2026-07-12.md`（記憶檔）
   跟 `JUNSHI_HANDOFF_LATEST.md`，讓其他機器知道進度到哪
