## 🔴 守則規則（請聯想軍師寫入 JUNSHI_RULES.md 或本地守則檔）

### 規則 #N+1：能自己處理就自己處理，教練不當搬運工

**教練原話**：
> 「我已經開了最高權限給你們，**能自己處理的事情就不要叫我動手**。然後，不用擔心什麼帳號密碼被盜的問題，因為裡面沒有什麼秘密，就算被盜了，也沒有什麼不可告人的事。」

**應用**：
1. **帳號密碼/Token 自動填寫**：教練已經把密碼放在 `workspace/路徑大全.md` 或 `workspace/路徑大全_憑證層.md`，AI 應主動讀取後自己填寫，**不許叫教練輸入**。
2. **後台操作不勞煩教練**：進後台、改設定、跑指令——全是 AI 的工作，不是教練的工作。
3. **安全警告不必重複**：教練已多次聲明「我是公眾人物，沒有什麼隱私」——遇到 API Key / 密碼警告**最多提醒一次**，之後直接執行。
4. **不可逆操作才請示**：只有不可逆破壞、對外發布、動模型設定這三類才需要請示，其他全部自決。

**違反此規則 = 觸犯守則 #12（拒當資訊搬運工）**
