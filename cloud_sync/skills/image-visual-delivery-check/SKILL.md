# 圖片交付視覺確認（執行細則 N4 交付前親眼驗證）

對應守則 #03（思考就是問問題，自我驗證再回答）、#15（說不知道比胡說八道更值得尊重）。

## 規則

任何圖片產出交付前，必須用 image 工具（Read 讀取圖片檔、瀏覽器截圖後親眼看、或iOS模擬器screenshot）**親自看過**一次，確認：

1. 內容正確——畫的是不是教練要的東西
2. **繁體中文無誤**——沒有簡體字、沒有錯字、沒有亂碼
3. 排版沒有跑版、沒有文字被裁切

## 鐵律

工具分析報告「沒問題」、程式邏輯上看起來對，**不算**已驗證。只有「我自己看過畫面」才算數。

這跟守則#03的精神完全一致：結論出來之前、作品出來之前、圖片出來之前，自己要先看過。
