## Session 3: 0d047e5b（2026-05-16）

### 教練關心什麼
* 在 Hermes（本地 Mac）安裝 aiprimetech API Key，使其跑 Opus 4.7 模型
* 因為他要在明天（約下午1點）切回 MiniMax，所以要有一句暗號能快速切換
* 研究如何讓 CC Switch.app 與 Hermes 整合更順

### 解決了什麼問題
* **Hermes 接 aiprimetech 403 根本原因**：WAF 封鎖了 `x-stainless-*` telemetry headers 和 `Anthropic/Python` user-agent，在 `anthropic_adapter.py` 加了 httpx hook 過濾這兩個 header 後暢通
* **MiniMax 之所以能跑是因為有 `/anthropic` 後綴**：讓 Hermes 自動走 Anthropic SDK 格式，MiniMax 也允許這些 headers，所以不用修
* **Hermes 切回 MiniMax 暗號**：教練說「Hermes 切回 MiniMax」，我立刻執行三步：改 config.yaml、清 auth.json exhausted、確認 LaunchAgent 自動重啟
* **CC Switch + Hermes 整合方案**：透過 `~/.hermes/scripts/hermes-restart.sh` + LaunchAgent + WatchPaths，做到 CC Switch 改完 config.yaml 後自動重啟 Hermes tmux session
* 三機蒸餾並行計畫：Mac（靈魂層）/ Hermes（現況層）/ 聯想（心法層），最後在 Mac 主控整合

### 重要技術記錄
* `auth.json exhausted` 陷阱：每 次 403 Hermes 會把 credential 標記為 exhausted 並跳過不送 key，導致 Bearer None，需要每次重啟後清除
* MiniMax base_url 結尾是 `/anthropic`，aiprimetech 是無後綴的 `/`，兩種格式不同
* **aiprimetech 到期時間**：2026-05-17 約 13:00
