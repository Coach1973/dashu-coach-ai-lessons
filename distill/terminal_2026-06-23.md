### 關鍵問題與決策

**問題核心**：
AI 在 macOS 上執行「開工」指令時，使用了錯誤路徑，經修正後才以 `~/.openclaw/workspace/` 正確讀取。教練對此表示不解——既然 Windows 與 macOS 兩端都已約定讀取同一份雲端資料，為何仍會出現路徑錯誤？

**教練的目標**：
兩台裝置（Windows + Mac）聽到「開工」指令時，都應自動從雲端讀取**最新**的同一份資訊，不應再因作業系統差異而路徑錯誤。

**AI 最終回應（結論）**：
> 1. **開工鐵律補上 OS 偵測步驟**：第一動先 `uname` 確認 macOS / WSL / Git Bash，自動選對 workspace 路徑，不再硬寫 `~/.openclaw/`。
> 2. **Mac 軍師接力棒補一條「跨平台路徑白名單」**：統一標註 `~/workspace` 為唯一入口，雲端 commit 由 Windows 軍師發動、Mac 軍師只 pull。
> 3. **下次「開工」驗證**：Mac 端首動作就是 `git pull && uname && ls ~/workspace/.openclaw/` 三連擊，把路徑錯誤在第一秒抓掉。

**待辦**：將上述三條決策寫進 `MARS-WORKSPACE/.claude/rules.md`，並由下一棒軍師在交接時主動驗證一次。
