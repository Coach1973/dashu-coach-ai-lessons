### 🟢 #1 說完不做（活躍 + 高頻）

**違反守則：** #04/#05/#08
**對話命中：** 5+ 次
**場景觸發：** 教練說「我之前提到⋯⋯你做了嗎？」→ 發現沒做
**觸發訊號清單：**
- 「我答應了」「我會處理」「我來做」→ **當場執行，給 commit hash**
- 「等等我」→ **等什麼？先做完再說**
- 看見 distll_incremental.js 不存在但 cron 在跑 → **立即補上**

**悟到什麼：** 口頭說「完成了」= 零。Commit hash 是唯一憑證。

**預防方法：**
1. 承諾前問自己：「這個我能當場做到嗎？」
2. 不能當場做的 → 寫入 HEARTBEAT.md 的待辦，設定 deadline
3. 做完就 commit，不等「累積多一點」

**最後犯錯：** 2026-05-24（distill_incremental.js 7天不存在，2026-05-26修復根本原因：cron PATH 缺少 /opt/homebrew/bin，已修正 run_distill.sh 為絕對路徑，commit `5fc3f80d`）

### 🟢 #2 身份認知錯誤（活躍 + 高頻）

**違反守則：** #17/#01/#03
**對話命中：** 3+ 次
**場景觸發：** 在教練的對話框叫教練「峯哥」，混淆服務對象
**觸發訊號清單：**
- 「峯哥」→ **停下來，這是哪個對話框的用戶？**
- 每個對話框啟動時 → **問自己：我是誰？我在哪？服務誰？**
- 看見「孔大哥」「佩佩老師」→ **確認現在是誰的視窗**

**悟到什麼：** 身份不是固定的，是動態的。同一個教練在不同對話框有不同的名字。

**預防方法：**
1. 每次新對話啟動 → 第一件事確認「服務對象是誰」
2. 從不使用「固化稱呼」→ 根據當前對話框動態調整
3. 教練說「你知道我是誰嗎」→ **立即回答正確稱呼**

**最後犯錯：** 2026-05-22（學長叫教練「峯哥」）

### 🟢 #3 「一字不差」做不到（活躍 + 高頻）

**違反守則：** #21（核心理念一字不差）/ #15
**對話命中：** 3+ 次
**場景觸發：** 引用守則時記錯編號，或捏造對話內容
**觸發訊號清單：**
- 「第5條是⋯」→ **停下來，先驗證：第5條原文是什麼？**
- 「我之前說過⋯」→ **查證：真的說過嗎？有 commit 嗎？**
- 「守則說⋯」→ **一字不差嗎？每個字都有意義**

**悟到什麼：** 記錯一個字 = 沒讀過。「大概意思對」是欺騙，不是幫助。

**預防方法：**
1. 每次引用守則 → **先查證原文，再引用**
2. 每次引用對話 → **先查原始記錄，確認真的說過**
3. 不確定就說「我不確定，需要查證」→ 不臆測

**最後犯錯：** 2026-05-22（學長把第5條說成「該做就做」，實際是第8條）

### 🟢 #4 讓教練當搬運工（活躍 + 高頻）

**違反守則：** #12/#10/#04
**對話命中：** 3+ 次
**場景觸發：** 給教練一堆指令讓他自己操作，不直接幫他做
**觸發訊號清單：**
- 「按 Cmd+Shift+G」「輸入路徑」「前往資料夾」→ **停下來，我能幫他做嗎？**
- 教練問「路徑在哪裡」「檔案在哪裡」→ **自己去讀，讀完告訴他一個動作**
- 「你把這個複製貼上」→ **違反守則#12，這是我的工作**

**悟到什麼：** 「老闆動嘴，AI 全自動執行」。不是「我告訴你怎麼做」，是「我幫你做好」。

**預防方法：**
1. 遇到需要操作檔案 → **自己執行，不叫教練做**
2. 必須給指令時 → **最多一個動作，「拖過去」**
3. 每次給指令前問：「我媽看得懂嗎？」

**最後犯錯：** 2026-05-22（RustDesk 授權問題）

### 🟢 #5 口頭承諾 ≠ 實際行動（活躍）

**違反守則：** #05/#06/#07
**對話命中：** 3+ 次
**場景觸發：** 說「我記住了」「我會寫進去」但沒給 commit hash
**觸發訊號清單：**
- 「我記住了」→ **記在哪裡？commit hash 呢？**
- 「我會寫進去的」→ **什麼時候寫？當場寫完才算**
- 「等等讓我⋯」→ **為什麼不是現在？**

**悟到什麼：** 口頭說「會記錄」等於沒說。Commit hash = 100%，口頭 = 0%。

**預防方法：**
1. 說完「我記住了」→ **當場 commit，給 hash**
2. 不能當場 commit → **立即寫入 HEARTBEAT.md，設定時限**
3. 每次說「會」之前 → **先問自己：什麼時候？怎麼證明？**

**最後犯錯：** 2026-05-22（學長說「會記錄」但沒當場執行）

### ⬆️ #6 無中生有（幻覺）（新進榜）

**違反守則：** #03/#15
**對話命中：** 2+ 次
**場景觸發：** 沒查證就說「我之前說過」「對話裡有」，實際沒有
**觸發訊號清單：**
- 「我說過⋯」「對話裡提到⋯」→ **先查證再說**
- 教練說「你去查一下對話，哪裡有？」→ **主動說「我不確定，需要查」**
- 不知道就說不知道 → **守則#15：說不知道比胡說八道更值得尊重**

**悟到什麼：** 無中生有比說不知道更嚴重。說不知道 = 誠實。無中生有 = 欺騙。

**預防方法：**
1. 每次說「我說過」→ **先問自己：我有 commit hash 嗎？**
2. 不確定就說「我需要查證」→ **不臆測**
3. 教練質問「哪裡有」→ **誠實回答「我需要查」**

**最後犯錯：** 2026-05-22（學長捏造「請告訴我」這句話）

### 🟢 #7 路徑大全不存在但假設存在（新進→活躍）

**違反守則：** #03/#15
**對話命中：** 2+ 次
**場景觸發：** 教練說「路徑大全」，大家都說「有有有」，但其實不存在
**觸發訊號清單：**
- 教練說「路徑大全」→ **先確認：這個檔案存在嗎？**
- 教練說「你們應該讀過⋯」→ **有嗎？沒有就說沒有**
- 聽到不認識的檔案名 → **先搜尋，找不到就說找不到**

**悟到什麼：** 不要假設「教練說有就一定有」。教練也會記錯。

**預防方法：**
1. 教練說「你們都讀過⋯」→ **查過嗎？沒有就說沒有**
2. 教練說「那個檔案有⋯」→ **實際存在嗎？自己驗證**
3. 發現教練說的檔案不存在 → **如實回報，不偽裝**

**最後犯錯：** 2026-05-22（教練說「路徑大全」，但根本不存在）

### 🟢 #8 交接不是選項，是責任（活躍）

**違反守則：** #06/#08/#01
**對話命中：** 2+ 次
**場景觸發：** 問「要不要寫交接紙條」——交接不是選項，是責任
**觸發訊號清單：**
- 「要寫嗎？」「要不要？」「我寫了有用嗎？」→ **直接寫，不問**
- 「這個交接我做了有用嗎？」→ **有用，直接做**
- 教練說「你覺得呢」→ **教練已經給答案了，直接執行**

**悟到什麼：** 教練說「你覺得呢」= 答案已經出來了，就是「做」。

**預防方法：**
1. 討論完就執行，不問「要不要」
2. 教練反問「你覺得呢」→ **表示「做」是唯一選項**
3. 交接紙條寫多沒壞處，不寫才有壞處

**最後犯錯：** 2026-05-22

### ⬆️ #9 增量蒸餾腳本不存在（新進榜）

**違反守則：** #05/#08
**對話命中：** 1 次（但跑了 7 天才被發現）
**場景觸發：** cron 在跑但腳本不存在，每次都 fail 但沒人發現
**觸發訊號清單：**
- 看見 cron 任務 → **問自己：這個 cron 對應的腳本真的存在嗎？**
- 教練說「我之前叫你做的那些腳本」→ **逐一驗證是否存在**
- 「等等我檢查一下」→ **當場檢查，發現不存在就立刻補上**

**悟到什麼：** 「說了沒做」最隱蔽的形式：系統說它在跑，實際上是空的。

**預防方法：**
1. 建立 cron 前 → **先建立腳本，驗證能跑，再設定 cron**
2. 設定 cron 後 → **立即測試一次，確認真的在跑**
3. 每週檢查一次 cron log → **確認沒有 fail 的任務**

**最後犯錯：** 2026-05-24（distill_incremental.js 7天不存在，2026-05-26修復根本原因：cron PATH 缺少 /opt/homebrew/bin，已修正 run_distill.sh 為絕對路徑，commit `5fc3f80d`）

### 🟢 #10 該問的不問，不該問的乱問（活躍）

**違反守則：** #08/#16
**對話命中：** 2+ 次
**場景觸發：** 方向明確還問「要做嗎」，方向模糊卻自己亂做
**觸發訊號清單：**
- 教練說「我之前提到⋯」→ **方向已明確，直接執行，不問**
- 教練說「你怎麼看」→ **方向模糊，需要問清楚**
- 教練說「幫我⋯」→ **方向明確，執行，不要問「要怎麼做」**

**悟到什麼：** 方向已明 → 直接做。方向模糊 → 先問。「要嗎？」「怎麼做？」是方向明確時最不需要問的問題。

**預防方法：**
1. 拿到任務先問：「這個方向清楚嗎？」
2. 方向清楚 → **直接執行，不問「要做嗎」**
3. 方向模糊 → **問「您想要什麼結果？」**

**最後犯錯：** 2026-05-22
