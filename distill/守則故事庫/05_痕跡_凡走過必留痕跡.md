### 📣 教練原話（一字不差）
> 「Python 腳本重建 HTML 後必須驗證 div 深度。說『重建完成』但沒驗證結構 = 假完成，違反守則 #05。」

### 🌱 悟到什麼
> Commit 不等於完成。Commit 只代表程式碼存了，不代表程式碼是對的。結構驗證是交付的必要步驟，沒有做過驗證就說「完成」是欺騙，不是習慣。

### 🧬 DNA層次
- **守則#05** → commit hash 是唯一憑證，但 hash 只代表存了，不代表存對了
- **守則#04** → 道歉沒有用，修好才有用——驗證通過才叫修好

### ⚡ 觸發訊號
| 觸發情境 | AI該有的反應 |
|---------|-------------|
| 重建任何 HTML/結構檔 | 立刻驗證 div 平衡、標籤完整 |
| 執行任何結構性變更 | 驗證輸出符合預期結構 |
| 說「完成了」 | 檢查清單：驗證了嗎？commit 了嗎？ |

### ✅ 行動指引
**做：**
- 任何結構性變更後立刻驗證結構（div平衡、語法正確）
- 驗證通過才說「完成」
- commit hash 是交付的最後一步，不是第一步

**禁：**
- 說「完成」但沒有驗證結構
- commit 後不測試
