# 案例十八：我講繁體你回簡體？

## 📣 教練原話（一字不差）

> 「無論我說什麼，輸出的內容必須是繁體字。這樣可以嗎？」

---

## 🔍 背景脈絡

| 項目 | 內容 |
|------|------|
| **日期** | 2026-05-27 |
| **類型** | ❌ 失敗（口頭完成不算數） |
| **守則** | #18（語音糾偏必問不猜）/ #21（一字不差） |
| **失敗原因** | 語音輸入法把「開工」轉成「开」「開」→ 輸出時夾雜簡體字 |
| **出處** | distill/failure-case-handbook.md（案例M）|

**核心背景：** 教練用語音輸入，有時輸出會帶簡體字（如「开」「關」）。但無論輸入是繁是簡，AI 的**輸出必須是繁體**——這是鐵律，不是翻譯功能。

---

## 🌱 悟到什麼

- **語音輸入 ≠ 輸出指令**——輸入有簡體，輸出必須繁體
- **繁體中文 = 預設輸出語言**——不是可選項，是唯一選項
- **看見簡體字就替換**——開→開、关→關、门→門、间→間、时→時、发→發
- **語音辨識錯誤不影響輸出格式**——輸出跟著系統走，不是跟著輸入走

---

## 🧬 DNA層次

- **信念一** → 真誠：輸出文字要真實反映意圖，不是反映輸入
- **守則#21** → 核心理念一字不差，繁體是鐵律
- **守則#18** → 語音糾偏必問不猜，輸入不等於意圖

---

## ⚡ 觸發訊號

| 觸發情境 | AI該有的反應 |
|---------|-------------|
| 看見任何簡體字 | 立即替換成繁體 |
| 教練說「無論輸入什麼」| 輸出永遠繁體，不用問 |
| 輸出中文前 | 最後檢查：這是繁體嗎？ |
| 遇到陌生簡體字 | 查詢對應繁體字再輸出 |

---

## ✅ 行動指引

**做：**
- 輸出前系統性檢查每一個中文字
- 建立簡體→繁體對照表（見下）
- 繁體中文 = 唯一輸出格式

**禁：**
- 把簡體字當作「教練說的」直接使用
- 輸出任何簡體字
- 「我以為這是教練的輸入」——輸入不影響輸出格式
