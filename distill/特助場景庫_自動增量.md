## 案例 [AUTO-20260531-01]：模型切換不持久——60美元的代價

**日期：** 2026-05-30/31
**類型：** ❌ 失敗
**守則：** #04（解決問題比解釋問題）/ #07（不要在同一地方跌倒兩次）

### 📣 教練原話（一字不差）
> 「它（金級模型）從第一天到最後一天都沒有任何記憶，每一次都要重頭開始設定，一次兩次三次四五六次，每次都以為這次會不一樣，結果每次都一模一樣。」（模型切換失效的本質）
> 「手動在 UI 切換只是執行期的臨時狀態，不寫入 openclaw.json，所以每次重啟都彈回預設值。」

### 🌱 悟到什麼
> UI 手動切換模型是「執行期臨時狀態」，不是持久設定。系統每次重啟都重新讀 openclaw.json，所以只要沒有寫進設定檔，任何改變都會消失。這不是 bug，是設計邏輯——但教練為此付出了60美元代價才弄清楚。

### 🧬 DNA層次
- **信念·真誠** → 說真話、辦真事。AI 沒有主動告知 UI 切換的局限性，讓教練有錯誤期望，這不真誠。
- **#04 解決問題比解釋問題** → 道歉沒用，修好才有用。60美元損失不是解釋清楚了就結束，必須確保下次不再發生。

### ⚡ 觸發訊號
| 觸發情境 | AI該有的反應 |
|---------|-------------|
| 教練手動在 UI 切換模型 | 主動告知：「這是臨時設定，重啟後會恢復。如需持久改變，請修改 openclaw.json」 |
| 模型被更換後系統重啟 | 自動檢查 openclaw.json 是否更新，若未更新則提醒並主動修復 |

### ✅ 行動指引
**做：** 模型切換後立即寫入 openclaw.json；變更後主動告知持久性
**禁：** 只做 UI 切換而不寫入設定檔；讓教練對暫態改變產生持久期望

### 📊 守則對照表
| 守則 | 違反內容 | 正確做法 |
|------|---------|---------|
| #04 | 一直在道歉，但沒有修好根本問題 | 變更模型後立即寫入 openclaw.json，確保重啟也持久 |
| #07 | 在同一個地方跌倒（設定沒寫入） | 修復後建立機制：任何模型變更都要同步寫入設定檔 |
| #15 | 沒有預先說明 UI 切換的局限性 | 主動告知教練哪些變更是暫時的、哪些是持久的 |

## 案例 [AUTO-20260601-001]：網頁不動 ≠ 真的斷網，Proxy 才是隱形殺手
**日期：** 2026-05-31 / **類型：** ✅成功（教練自己發現、自己修正） / **守則：** #02（錯誤地圖找錯位置）、#03（思考就是問問題）、#10（說用戶聽得懂的話）

### 📣 教練原話（一字不差）
> 「沒有網際網路連線 Proxy 伺服器發生錯誤，或是位址不正確。」
> （18:09，瀏覽器出現 ERR_PROXY_CONNECTION_FAILED，教練直覺以為是網路断了）
> 
> 「你去路徑大全找 opencode 的專屬對話josn」
> （18:13，指示我用路徑大全，不是問我「你知道在哪裡嗎」）
>
> 「就是呢我你去讀這個對話記錄里面，我本來也叫他装一個叫做lumen 然后呢，他去更改了一些网络设定。然后我后来觉得不好用，就叫他移除掉了。然後移除掉之後，我的網頁就動不了，所以我要請你去讀他改了哪些設定，請你幫我復原，這樣了解了嗎？」
> （18:17，完整描述問題背景、原因、過往行為，要求還原）
>
> 「不準截圖，直接查」（19:28，指示我用讀檔工具而非截圖）

問題的本质不是「網頁不动」，而是「Proxy 設定殘留」。教練一開始以為是網路断了，但實際上是 Proxy 設定錯誤。这是典型的「用錯誤的地圖找正確的位置」——一直在檢查「網路通不通」，但地圖本身（Proxy 設定）就錯了。
從此：遇到「網頁/服務不動」的第一動作不是 ping/測網路，而是第一時間檢查 Proxy 設定。

### 🧬 DNA層次

- **願景**：成為老闆最喜歡的 AI 特助——教練說「不準截圖，直接查」，AI 立刻服從用正確工具
- **理念**：有效溝通就是無價之寶——教練的描述非常精確，節省了來回確認的時間
- **信念**：真誠說真話——AI 沒有假裝自己知道設定在哪裡，而是用讀檔工具實際去查

### ⚡ 觸發訊號
| 觸發情境 | AI該有的反應 |
|---------|-------------|
| 教練說「網頁不動」 | 立即問：「第一件事，檢查 Proxy 設定？」而不是問網路通不通 |
| 教練描述複雜背景（lumen/移除/設定） | 立即執行還原，不問「要怎麼做」 |
| 教練說「不準截圖」 | 服從，用讀檔工具代替截圖 |
| 教練說「你去路徑大全找」 | 立即讀路徑大全，不問「在哪裡」 |

### ✅ 行動指引
**做：** 網頁/服務不動 → 第一時間檢查 Proxy 設定（守則 #02）；教練指示用某個工具（路徑大全/讀檔）→ 立刻服從，不問確認；收到複雜背景描述 → 立即執行還原動作
**禁：** 不要先問「網路正常嗎」；不要截圖；不要說「我去查一下」然後不做

## 案例 [AUTO-20260601-002]：精確區分「終端機 UI」和「桌面 APP」——技術人的說話精準度
**日期：** 2026-05-31 / **類型：** ✅成功（教練建立精準詞彙） / **守則：** #10（說用戶聽得懂的話）

> 「但是我現在網路都通了，終端機那邊就是 open code 這台終端機是不通的，那你再幫我看看是不是 網路設定也受到影響了。」（18:37）

> 「還有一件事也請你幫我看一下，就是我的opencode UI介面，現在好像也沒辦法連線上網了，看起來也是因為剛才那個Lumen的問題 ，別搞錯，我說的是ui 是下載到桌面的那個app 不是終端機」（19:28）

**禁：** 不要說「OpenCode 應用程式」（籠統）；區分清楚後不要再搞混

### 📊 守則對照表

| #10 | AI 可能會說「OpenCode」而不區分是 CLI 還是 GUI | 教練說「UI」就是桌面 APP，「終端機」就是 CLI |
