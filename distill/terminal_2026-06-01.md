# 終端機對話蒸餾 2026-06-01

## Session c3f27509（2026-05-31 晚間）

### 問題一：Proxy 設定殘留（Lumen 移除未清乾淨）
- **現象**：瀏覽器出現 `ERR_PROXY_CONNECTION_FAILED`，教練以為沒網路
- **根本原因**：Lumen TLS 攔截代理移除時，HTTP/HTTPS/SOCKS 三個 Proxy 設定沒清乾淨
- **解決**：全部禁用，網路恢復正常

### 問題二：OpenCode 終端機無法連線
- **根本原因**：`ANTHROPIC_BASE_URL` 環境變數 + `opencode.jsonc` 裡的 `baseURL` 仍指向 `127.0.0.1:9090`（Lumen 代理位址）
- **解決**：將 `baseURL` 改回直連位址 `https://opencode.ai/zen/go/v1`

### 問題三：OpenCode UI（桌面App）也連不上
- **原因**：UI 和終端機共用同一個設定檔，環境變數殘留問題相同
- **解決**：系統 Proxy 禁用後已自動恢復（Log 顯示 02:22 後已正常），只需重啟 UI 即可

### 教練關心的重點
1. 網頁不動 → 其實是 Proxy 設定問題，不是真的斷網
2. OpenCode 連不上 → Lumen 改過的設定要完全復原
3. Mounty 可以關 → 只是 NTFS 寫入工具，平常沒用到可直接Quit

### 重要決策
- **不要輕易裝 Lumen**：移除後會留一堆殘留設定，影響系統 Proxy、OpenCode UI、終端機環境變數，代價大
- **網頁不動先查 Proxy**：第一時間不是問「網路正常嗎」，而是檢查 Proxy 設定
