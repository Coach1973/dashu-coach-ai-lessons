## 📋 工作流（兩維度，逐故事跑一遍）

### 維度 A：教練原話出處真實性

對 `distill/守則故事庫/01_*.md` ~ `21_*.md` 的每一份檔案：

1. 找到「📣 教練原話（一字不差）」段落
2. 找到「**出處：**」標的檔案路徑+行號
3. 開那個檔案那行附近 ±50 行
4. 比對原話是否真的存在（允許微小標點差異，但語義+關鍵詞必須一致）
5. 結果分類：
   - 🟢 **可查證**：原話在指定出處找得到
   - 🟡 **位置偏移**：原話存在於該檔案，但行號偏差 >50 行
   - 🔴 **查無此話**：該檔案找不到這句話 → **可能編造，軍師必審**

### 維度 B：跟既有 128 庫的重複度

對 `distill/守則故事庫/01_*.md` ~ `21_*.md` 的每一份：

1. 抽出「故事短標題」「教練原話」「情境關鍵詞」
2. 在 `distill/特助場景庫_格式D_128合併版.md` 全文搜尋是否有近似案例
3. 判斷三維度：
   - 教練原話相似度（一句話有沒有出現過）
   - 情境相似度（事件背景）
   - 守則對應
4. 結果分類：
   - 🟢 **完全獨立**（三維度都無重疊）
   - 🟡 **部分重疊**（情境或守則相似但原話不同）
   - 🔴 **疑似重複**（教練原話幾乎一樣）→ **軍師必審**
