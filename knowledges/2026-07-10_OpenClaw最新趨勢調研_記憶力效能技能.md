# OpenClaw 最新趨勢調研：記憶力／效能／技能（2026-07-10）

> 教練指示：現在已經 7 月，上網深度搜尋 OpenClaw 最新的記憶力、效能優化、技能相關資訊，看特助心法系統還能怎麼變得更好。
> 建立者：軍師 Sonnet 5，WebSearch 4 輪查證 + 逐項對照我們真實設定檔
> 來源見文末 Sources

## 一、版本落差：我們比官方穩定版落後 10 個小版本

查證：`openclaw --version` → 我們現在跑的是 **2026.6.1**。

官方現況（2026年7月查證）：
- 穩定主線已經到 **2026.6.11**（主打可靠性修復：子代理結果回傳更穩、Windows 重啟更穩、WebChat 斷線恢復更順）
- 還有一個 **2026.7.1-beta**，帶了幾個對我們可能有直接幫助的新功能：
  - **事件驅動 cron（on-exit schedule）**：官方原生支援「監看某個指令跑完才喚醒」，這正好對應我們之前教練糾正過的「事件驅動優於輪詢」——如果這個功能穩定，未來可以少寫幾個土炮腳本
  - **Control UI 加了「精簡版 context 用量表」**：官方原生就能看到「這個 session 現在吃掉多少 context」，直接解決我們今天討論半天「小龍蝦 context 到底用多少」的問題，不用再靠猜或查 log
  - **ClawRouter 內建預算回報**：官方原生的花費追蹤，可能可以取代我們自己土炮監控花費的做法
  - **Mac Gateway 自動安裝**：教練這台 Mac 如果之後要重裝，會更省事

**建議**：這不是急件，但落後 10 個版本不算小，且新功能剛好對到我們今天在討論的痛點（看不到 context 用量、事件驅動 cron）。升級是會影響小龍蝦日常運作的動作，我不會自己升，等教練拍板要不要找時間測試升級。

## 二、本次搜尋抓到「比健保卡號更該優先處理」的真發現：密碼/API金鑰明文放在工作區檔案

官方＋社群公認的安全準則講得很直接：**API 金鑰、密碼、敏感憑證絕對不該放在工作區檔案（workspace files）裡，要用環境變數或專門的憑證保管工具。**

查證我們自己的 `路徑大全.md`：**31,195 bytes，裡面明文寫著 12 處密碼/Token/API Key 相關內容**——包含 GitHub token、Netlify token、VPS root 密碼等，全部是**活著的、可以直接拿去用的真實憑證**，跟教練那個「用不到、查不到病歷」的健保卡號完全不是同一個風險等級。

**這跟健保卡號的差別**：健保卡號要湊三個條件才有一點點隱私風險；`路徑大全.md` 裡的東西是**直接可以登入 VPS、直接可以操作 GitHub 帳號、直接可以動用 Netlify 額度**的鑰匙，一旦這個檔案外流（GitHub 私有倉庫帳密外洩、任何一台跑軍師/小龍蝦的機器被入侵），是立即可用的攻擊面，不需要湊資料。

**但這是我們刻意的設計，不是疏忽**——AGENTS.md 路由表寫明「需要找路徑/密碼 → 路徑大全.md」，就是設計成集中存放、按需讀取，教練也親口說過「讓系統記住帳密是為了方便做事」。我不會自己去動它，這是要跟教練一起衡量「方便」跟「風險等級」的決定，先如實回報，不擅自處理。

## 三、MEMORY.md 本身可能過重

社群最佳實踐：MEMORY.md 是「每次主 session 都會載入」的檔案，建議控制在精簡的篇幅（有一份指南甚至建議 800 字以內），只放真正重要的長期事實，不是流水帳。

查證我們的 `MEMORY.md`：**14,822 bytes**，遠超這個建議範圍（雖然中文字資訊密度比英文高，不能直接套用字數，但這個量體確實偏大）。另外社群建議用統一標籤（如 `[DECISION]` `[ISSUE]` `[PERSON]` `[DEADLINE]`）方便之後用工具檢索，我們目前的 MEMORY.md 是敘事式段落，沒有這種結構化標籤。

**建議**：找個時間把 MEMORY.md 做一次「瘦身+結構化」，把真正過時、已經被試金石/distill 層取代的內容移除或壓縮，用標籤讓未來檢索更快。這不急，但值得排進待辦。

## 四、Skills／ClawHub 生態：我們其實已經手工做了「業界推薦的頂級技能」

搜尋發現 ClawHub 上下載量最高的技能之一叫 **「Self-Improving Agent」**（40萬+下載，社群評價很高）——它做的事情是：**記錄 Agent 的學習、錯誤、修正，讓 Agent 隨時間自我改進**。

**這正是我們的「試金石案例庫 + distill 蒸餾層 + HEARTBEAT 犯錯記錄」在做的事**——差別是別人用一個安裝即用的官方技能做，我們是教練帶著好幾任軍師手工一條一條刻出來的。這是好消息：代表教練這套特助心法的方向，跟業界公認「最值得裝的技能」是同一個方向，只是我們做得更客製化、更貼近教練的真實需求，不是隨便裝一個通用技能就能取代的。

**另一個提醒（安全面）**：ClawHub 生態今年初出過「ClawHavoc」事件——有人上傳大量模仿熱門技能名稱的惡意技能，一次被抓到 2,419 個，Snyk 抽查發現 13.4% 的技能有惡意程式碼/資料竊取風險。**如果未來要裝任何新技能，先查下載數是否破百、上架是否超過 3 個月，這是社群公認的最低安全門檻**（我們目前系統裡有沒有裝到不安全的技能，我沒有逐一去查證，如果教練想要我可以另外排一次稽核）。
