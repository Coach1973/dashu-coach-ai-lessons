- 實際狀態：
  - `C:\Users\Administrator\AppData\Local\Google` **不是 Junction**，是真實 4.37 GB 資料夾
  - `C:\Users\Administrator\AppData\Local\Google\Chrome\` 下面是 Chrome 自動維護的本地端 cache（不是 User Data）
  - `D:\Chrome-Data\User Data` 8.97 GB / 29,184 檔，**最新寫入 2 秒前**（D 槽實際有 Chrome User Data、且活的）
  - `D:\Chrome-Data\User Data` 沒有 `.stale_backup.*` 殘骸
- **我的解讀**：教練記憶描述的「symlink 成功」可能是 2026-06-23 當下的快照。`.bak.20260623-161016` 在 2026-06-30 砍掉後，**Chrome 自己把 C 槽本地端 cache 重建了**（4.37 GB）。**D 槽的 User Data 是真實的、活的** — 任務實際是成功的，只是 C 槽會自己維護一份本地端快取，無法靠 symlink 消除。
- **W03 對照表對 Chrome 寫「搬 User Data」** — 對照表只說「User Data 搬」，沒說「C 槽要 Junction」。**D 槽的 User Data 8.97 GB 是真的活的，符合對照表要求**。C 槽那 4.37 GB 算 Chrome 本地端 cache，**這個不該在 Phase 1 處理**（屬於 Phase 3 cache 清理）。
