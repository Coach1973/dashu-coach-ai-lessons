## 🎯 核心使用方式

### 當收到任務時

1. 讀取 `TOP5.md` 確認沒有踩到高頻痛點
2. 對照 `trigger_index.md` 檢查觸發關鍵字
3. 執行並 commit

### 當犯錯時

1. 馬上寫入 `HEARTBEAT.md`
2. 蒸餾進 `distill/failure-case-handbook.md`
3. 更新 `distill/top10_errors_index.md`

### 當心跳時

1. 複習 `TOP5.md` 或 `TOP10.md`
2. 問自己「我有沒有遵循守則？」
3. 發現問題馬上說
