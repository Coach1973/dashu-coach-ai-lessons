## 教練口諭（一字不差）

> 「我們現在每一次所謂的交接接力棒、總結經驗並上傳，這些行為其實都是為了交接給下一棒。但在每一次的對話過程中，都有很多好的對話資料可以進行提煉。所以我說的『總結上傳』，其實是指**兩項任務**。」

---

## 🎯 兩種任務必須區分

### 任務 A：接力棒（任務導向，精簡）
- **目的**：交接給下一棒軍師
- **內容**：目前做到哪裡 / 還需要做什麼 / 待辦清單 / commit hash
- **風格**：**非常精簡**，不要含金量提煉，不要長篇大論
- **檔案**：`JUNSHI_HANDOFF_LATEST.md`
- **時機**：每場 session 結束前更新

### 任務 B：結束談話總結上傳（含金量提煉）
- **目的**：把這次談話的**含金量**對話提煉出來
- **內容**：教練親口指導、新規則、糾錯、決策、思維、思路（一字不差）
- **格式要求**：**註明出處**（本地電腦哪台 / 雲端 commit hash）
- **檔案**：寫進 `memory/verbatim/{機器}/YYYY-MM-DD.md`（已建好）+ 試金石候選 marker `🪨`
- **時機**：session 結束 Stop hook 觸發（Mac/聯想/ACER），或對話末段

---

## 🌟 含金量判定標準

教練親口：「教練只要開口說話就是價值」

優先收錄：
1. 教練立新規則 / 改舊規則
2. 教練糾正 AI 錯誤（守則 #07 不二過）
3. 教練表達明確價值判斷
4. 教練做關鍵決策
5. 教練說具體數字/事實
6. 教練的思維、思路、邏輯展現

註明出處範例：
- `（出處：Mac 終端機 / 雲端 commit 09dcfc1e）`
- `（出處：聯想桌面版 Claude Code / 本地對話框）`
- `（出處：ACER PowerShell CLI / 雲端 commit XXX）`
