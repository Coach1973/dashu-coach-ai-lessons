## 一、改了什麼

### 1. 主題區（`#eco`）：大卡片改成「一個主題一行」的清單

- 原本四張大卡片（2 欄、大圖），現在每個主題排成一行：**左邊小圖、中間標題加一句說明、右邊超連結**。
- 四個主題照原本的順序：媒體與導師、綠能科技、生命農業與水、公益路跑。標題、說明文字一字沒改。
- **原本 10 個連結全部保留**，網址和字都沒改（3＋2＋4＋1 個）。
- 圖片還是原本那 4 張，只是縮成 480×360 的小圖另存成 `img/thumb-*.jpg`，比原圖輕很多（每張 36～55KB，原圖 227～357KB）。
- 原本卡片上的數字（3,600、116、167、7、43、300+、+10%、3 合 1、04.18、12,000、100）規格沒提，我**沒有刪**，收進每一行的「＋ 看關鍵數字」，點了才展開。最底下那行數據來源說明也留著。
- 以後加主題：HTML 裡有註解，複製一整段 `<li class="topic rv">…</li>` 貼在最後，改圖、ROOT 編號、標題、說明、連結就好。

版面寬度：
- 桌機（1040px 以上）：小圖｜標題＋說明｜連結，三欄一行
- 平板：小圖在左，標題、說明、連結疊在右邊
- 手機（640px 以下）：小方圖＋標題在上，說明和連結在下面整寬

### 2. 節目單＋百集計畫合併成一區（`#episodes`）

- 原本「節目單」和「100 集，100 位領跑人」是兩區，中間還隔著主題區。現在合成一區，放在原本節目單的位置（理念後面、主題區前面）。
- 標題用「**100 集，100 位領跑人。**」，原本兩區的介紹文字接在一起照原文保留，「在 SoundOn Podcast 收聽全部」按鈕、Podcast 封面圖、四個步驟（加入→坐到榮樹下→上架→帶動報名）也都留著。
- **1～100 格**：
  - 已播出的格子亮金色，桌機上寫號碼和來賓短名（吳錦昌、楊境界、周總、黃國彰），手機上寫號碼和 ▶。
  - 點已播出的格子會**跳出一個視窗**，顯示那一集的：第幾集、來賓、每個版本（重點節錄版／實況轉播版）的標題、日期、長度、介紹、「到 SoundOn 收聽」按鈕。最新一集會標「最新一集」。
  - 來賓在本頁已經有專題網頁的，視窗最下面會有「認識來賓」連結：
    - 第 2 集 楊境界博士 → 楊博士 ‧ 空氣取水（`/curated/hnv-cc/`）
    - 第 3 集 約瑟布 周總 → 約瑟布 ‧ 永續綠牆（`/curated/joseph-cloth/`）
    - 第 4 集 黃國彰 → 發明家黃國彰專題（`/curated/inventor/`）
    - 第 1 集 吳錦昌：本頁沒有他的個人網頁，所以沒放（見第四段）
  - 視窗可以按右上角 ×、按 Esc、或點視窗外面關掉。
  - 其他格子寫「**等你**」，點了跳到嘉賓席的「**我也想坐上嘉賓席**」報名區。
  - 格子上面有一行說明：「已播出 N 集：點一下看內容、收聽」「等你：點一下報名嘉賓席」。
- 每排格數：桌機和平板 10 格，手機（640px 以下）6 格。400px 寬時每格 55×64px，360px 寬時大約 48×64px，都大於手指好按的 44px。
- 資料來源：
  - 原本節目單上 4 集（5 個版本）的文字，我原封搬進網頁 script 裡的 `BASE` 清單當底。
  - 開頁時照舊呼叫 `/api/rongtree/episodes`。`BASE` 裡沒有的集數會自動補上：重點節錄版排到下一個號碼（照日期先後），實況轉播版併進同一位來賓那一格。上方「已播出」清單和「已播出 ‧ N 集」也會跟著更新，跟原本的自動更新一樣。
  - API 讀不到，就只顯示 `BASE` 的 4 集，頁面不會壞。

## 三、我怎麼驗證的

雲端這邊連不到 `event.bymyway.com`（網路被擋，回 403），所以我在雲端自己架了一個**模擬伺服器**，路徑跟正式站一樣（`/curated/rongtree/`、`/api/rongtree/episodes`、`/api/rongtree/prep`、`/static/nav-burger.js`）。用 Playwright 的 Chromium 瀏覽器開頁測試。模擬用的假資料只放在雲端暫存區，**沒有進倉庫**。

測了三種 API 情況 × 兩種寬度（**手機 400px、桌機 1440px**），另外截圖看了平板 1024px 和小手機 360px：

1. API 回新集數（假資料：一個新的實況版和兩集新節目，而且故意不照日期排）→ 第 5、6 格照日期亮起，實況版正確併進第 4 格，上方已播出清單和集數都更新
2. API 只回原本那 5 筆 → 亮 4 格
3. API 壞掉（回 500）→ 照樣亮 4 格，沒有錯誤

每種情況都自動檢查了下面這些，**132 項全部通過**：
- 沒有 JavaScript 錯誤
- 格子剛好 100 格、號碼 1～100 照順序，亮的格子數量和名字對
- 空格子都寫「等你」、都連到 `#seat-join`，字沒有被切掉
- 手機格子最小 55×64px（大於 44px）
- 頁面沒有左右多出來、可以橫向滑的部分
- 頁面上所有 `#` 連結都找得到位置；舊網址 `…/#hundred` 打開會停在格子上方
- **畫面上所有字都 ≥ 20px**（只有頁尾那排是教練 10/14 特准的 16px，原本就有，我沒動）；另外也直接掃了 CSS 原始碼，沒有任何新的 font-size 或 font 簡寫小於 20px
- 主題區 4 行，連結數 3／2／4／1 跟原本一樣
- 點第 1 格會跳出 2 個版本（節錄版 12:15、實況版 1:14:42），日期、SoundOn 網址正確；第 4 格有「發明家黃國彰專題」
- 視窗按 ×、按 Esc、點外面都會關掉
- 點空格子會滑到「我也想坐上嘉賓席」，標題沒有被頂部選單擋住

**滑動長度比較**（節目＋主題＋百集這三塊加起來）：
- 手機 400px：8,947px → **5,050px**（少了大約 44%）
- 桌機 1440px：5,244px → **3,536px**

截圖我自己逐張看過（桌機、平板、手機 400、小手機 360、跳出視窗），有看到並修好兩個小問題：360px 寬時大標題「100 位領跑人。」被切成兩行，還有 SoundOn 按鈕折兩行時字黏在一起。

## 四、沒做完、不確定、要請軍師在 Mac 上確認的

1. **真正的 API 那 8 筆我看不到。** 我只知道格式，不知道內容。請在 Mac 上打開分支版本，看格子亮了幾格、每格是誰。可能的狀況：
   - 如果 8 筆裡多出來的 3 筆是第 2～4 集的實況版，應該還是亮 4 格，第 2～4 格的視窗裡會多一個「實況轉播版」。
   - 如果是新的集數，就會亮第 5 格以後。
   - 實況版是用「標題裡有沒有來賓短名」來對應哪一格的（例如「吳錦昌董事長 ‧ 完整對談」裡有「吳錦昌」）。如果實況版標題沒寫名字，可能會對錯格，或自己多開一格。
   - 如果 SoundOn 上同一集的 id 跟頁面上寫的不一樣，那一集會被當成新集數多亮一格。
2. **自動補上的集數，格子上的短名是程式自己切的**：取標題最後一段（「專訪瘋子發明人 黃國彰」→「黃國彰」）。標題格式不一樣的話可能切得怪。要改的話，在 script 的 `BASE` 清單裡照現有格式手動加那一集（`who` 是格子上的短名，`guest` 是視窗標題）。
3. **自動補上的集數沒有「認識來賓」連結。** 要加的話，在 `BASE` 裡那一集的 `pages` 加 `['連結文字','網址']`。
4. **第 1 集吳錦昌董事長沒有「認識來賓」**，因為本頁沒有他的個人網頁。要不要連到 Run for Future 頁，或連到本頁「樹下的人」，請教練決定。
5. **楊境界博士 ↔「楊博士 ‧ 空氣取水」**：本頁只寫「楊博士」。我是看第 2 集介紹提到「漢諾威研發團隊」、網址是 `hnv-cc`，判斷是同一位，請確認。
6. **主題區的數字**我收進「＋ 看關鍵數字」。教練如果覺得不需要，把每行的 `<details class="nums">…</details>` 和最底下的 `eco-note` 那段刪掉就好。
7. **主題區有兩處寫死「四」**：眉標「一棵樹，四條氣根」，還有說明文字「媒體、綠能、生命農業與公益路跑」。加第五個主題時這兩處要一起改。我沒有先改，因為這是文案。
8. **節目單文字從 HTML 搬進 script**：格子本來就是 JavaScript 畫的（原本的 100 片葉子也是），所以關掉 JavaScript 就看不到格子。不過上方「已播出」清單和「在 SoundOn Podcast 收聽全部」按鈕不靠 JavaScript 也能用。各集介紹要點開視窗才出現，搜尋引擎在一開頁的畫面上看不到；如果在意搜尋排名，可以再討論。
9. **`nav-burger.js` 我看不到原始碼**，只確認它要複製的 7 個連結都找得到位置。請在 Mac 上用手機寬度點一次漢堡選單，確認「百集節目」會跳對地方。
10. **字型**：雲端連不到 Google Fonts，截圖是用替代字型。正式字型（思源宋體／黑體）的字寬會差一點，請在 360px、400px 寬看一下大標題和格子裡的「等你」有沒有擠到。

12. **分支**：雲端環境預設叫我用 `claude/funny-fermat-941y7i`，我照教練這次的交辦改用 `claude/rongtree-redesign`。funny-fermat 那個分支我沒有放任何東西。
