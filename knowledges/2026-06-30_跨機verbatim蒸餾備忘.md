## 三、軍師的具體交付物

### A. 聯想端（Win）script

- 檔名建議：`scripts/distill_and_push_聯想.cmd` 或 `.ps1`
- 觸發：cron job，建議每 2 小時跑一次（與 Mac 端 distill_incremental.js 同頻率）
- 行為：
  1. 讀 `memory/YYYY-MM-DD.md` 抓 🦞 小龍蝦 bullet points（沿用 Mac 端規則）
  2. 蒸餾結果加 `[聯想]` 標籤
  3. `git add` + `git commit -m "auto: 聯想對話蒸餾 YYYY-MM-DD"` + `git push` 到 `Coach1973/mac-openclaw-workflows` 的 `memory/verbatim/聯想/` 子目錄

### B. ACER 端 script

- 檔名建議：`scripts/distill_and_push_acer.sh`
- 觸發：cron job，每 2 小時跑一次
- 行為：
  1. 同聯想端
  2. 標籤改為 `[ACER]`
  3. 推到 `memory/verbatim/ACER/` 子目錄

### C. Mac 端 `distill_incremental.js` 修改

- 原本只讀本機 `memory/YYYY-MM-DD.md`
- 改為同時讀雲端拉下來的：
  - `memory/verbatim/聯想/YYYY-MM-DD.md`
  - `memory/verbatim/ACER/YYYY-MM-DD.md`
- 每段蒸餾前綴標記來源：`[Mac] / [聯想] / [ACER]`
- 驗證：open session 開工時，學長能直接讀到三機對話

### D. 試金石候選標記（關鍵！教練真正想要的）

- 蒸餾結果中，符合**試金石標準**的段落（教練犯錯場景 / 教訓 / 最佳實踐）要額外加 marker：`🪨 試金石候選：<一句話總結>`
- Mac 端 `distill_incremental.js` 掃到 marker 時，自動彙整到 `distill/試金石_案例庫.md` 的候選區（教練有空再決定收不收）
- 試金石標準請參考 `distill/top10_errors_index.md` 與 `distill/試金石_案例庫.md` 現有範例

### E. 接力棒機制不能迴歸

- 目前的接力棒摘要（commit message / handoff）功能必須保留
- 跨機 commit 掃描 hook（`scan_cross_machine_commits.sh`）也要繼續跑
- 新功能是**疊加**，不是**取代**

## 四、已知風險與注意事項

1. **ACER 端 outbound 推送**：ACER 通常在內網。已知有 inbox hook（commit `6b69df3a` 顯示 ACER inbox hook setup done，2 letters archived），代表 outbound 有通道。但 git push 是否暢通請軍師先驗證。
2. **verbatim 檔案大小**：聯想/ACER 對話量可能比 Mac 大（任務密集），蒸餾後 markdown 也會累積。雲端 repo 容量請估算，必要時加 .gitignore 規則只保留摘要。
3. **三機時鐘不同步**：蒸餾要統一用台灣時間（UTC+8），跟 Mac 端現行做法一致。聯想/ACER 端如果用 UTC，要做轉換。
4. **隱私**：教練跟特助的對話屬於內部資料，雲端 repo 是私有的（Coach1973/mac-openclaw-workflows），OK；但要避免把個資（如 LINE ID、電話）推到外網可見處。
5. **不可打斷現有蒸餾**：聯想/ACER 端如果已有自己的 verbatim 蒸餾腳本（cron 跑著），先盤點再改，不要直接覆蓋。
