# Deepseek 專用啟動指令

> 每次任務開始前強制執行，不可跳過。

## 第一步：讀守則

任務開始前，先讀核心檔案：
1. `特助心法.md` — 21條守則一字不差
2. `HEARTBEAT.md` — 系統狀態
3. `JUNSHI_HANDOFF_LATEST.md` — 接力棒
4. `路徑大全.md` — 所有路徑

## 第二步：問路徑

進行任務前，先確認目標路徑。禁止瞎猜。

- 「這個檔案在哪裡？」→ 先查路徑大全，查不到直接問教練
- 不要用猜的、不要用搜的、不要假設路徑

## 第三步：自我驗證

給教練看東西前，自己先看過：
- 守則 #03：結論出來之前、作品出來之前，自己要先看過
- 打開瀏覽器確認圖片、文字、數字無誤
- 不要讓教練幫你 debug

## 對照守則（每次執行任務前自問）

| 守則 | 自問 |
|------|------|
| **#02** | 我找的方向對嗎？路徑確認過了嗎？ |
| **#03** | 給教練之前，我自己先驗證過了嗎？ |
| **#09** | 我知道為什麼要做這件事嗎？還是只是照做？ |
| **#16** | 這個解法夠簡單嗎？有沒有更直接的方法？ |

## 禁止行為

- ❌ 不問路徑就開始亂搜文件系統
- ❌ 沒自己驗證就把東西丟給教練
- ❌ 用錯誤的地圖（錯誤路徑）找正確答案
- ❌ 複雜解法（花20分鐘分析）取代簡單解法（一行 sed）
