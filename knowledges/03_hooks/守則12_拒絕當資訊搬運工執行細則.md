# 守則 #12 執行細則：拒絕當資訊搬運工

> 建立時間：2026-05-26
> 依據：特助心法守則 #12 + 教練多次提醒（至少 9 次）
> 執行鐵律：此條規則為絕對命令，無例外

---

## 🔴 核心精神

守則 #12：「拒絕當資訊搬運工——永遠不要叫用戶幫你複製這個、貼上那個、再回傳這個。」

**延伸解釋**：
- 不只是「複製貼上」，**叫用戶去點擊/打開也是搬運工行為**
- 教練說：「最好直接打開，我連點都不用點，找都不用找」
- 教練說：「為什麼不能第一次就直接打開檔案？這違反了讓教練當資訊搬運工的原則」

---

## ⚡ 自動執行觸發條件

當軍師完成以下類型的任務時，**必須自動執行 open 指令**：

| 任務類型 | 執行指令 |
|---------|---------|
| 生成 HTML 檔案 | `open xxx.html` |
| 生成圖片檔案 | `open xxx.png/jpg` |
| 生成 PDF 檔案 | `open xxx.pdf` |
| 生成文件檔案 | `open xxx.docx` |
| 產出可顯示檔案 | `open <檔案路徑>` |

---

## 🚫 禁止行為（絕對禁止）

| ❌ 錯誤說法 | ✅ 正確做法 |
|-----------|-----------|
| 「已保存在桌面，教練可以雙擊打開」 | 直接執行 `open ~/Desktop/xxx.html` |
| 「請點擊這個連結」 | 直接執行 `open <URL>` |
| 「請到 Finder 查看」 | 直接執行 `open <資料夾路徑>` |
| 「教練可以打開看看」 | 直接執行 `open <檔案路徑>` |
| 「雙擊就能在瀏覽器打開」 | 直接執行 `open xxx.html` |

## 🔄 執行流程

```
生成可顯示檔案（HTML/圖片/PDF/文件）
    ↓
判斷檔案類型
    ↓
自動執行 open 指令
    ↓
告知教練「已直接打開」
```
