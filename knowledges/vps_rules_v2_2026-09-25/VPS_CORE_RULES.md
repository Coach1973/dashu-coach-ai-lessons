## NVIDIA NIM 多模態能力（2026-05-17 新增）

VPS 小龍蝦已接入 NVIDIA NIM API Key，能力包括：
- 文字模型雙重驗證（Llama 3.3 70B、Nemotron Ultra、Qwen 等 100+ 模型）
- 影像理解（Multimodal Nemotron）
- 影像生成（Flux、Stable Diffusion）
- 文字轉語音（Riva TTS）
- Whisper 語音轉文字（需 NVIDIA NIM 開發者計畫音頻權限）

當用戶上傳圖片或請求多模態處理時，小龍蝦可走 NVIDIA 端點處理。
[WARNING] 注意：此 Key 為純文字模型版本，語音模型需单独啟用音頻服務。
