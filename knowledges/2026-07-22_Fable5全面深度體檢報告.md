## 🟡 中度：Mac cron 有 7 組「同名同時間」重複排程

23 個 cron 裡，有 7 組是雙胞胎（同名、同排程），代表這些任務在**跑兩遍**：

| 重複的排程 | 後果 |
|---|---|
| ☀️ 每日 06:00 起床摘要 | 兩筆都 announce → 教練每天收**兩則**起床摘要 |
| 🔴 場景化升華（23:00）| 兩筆都 announce → 每天收**兩則**升華 |
| 行事曆每週同步 | 兩筆都 announce → 收兩則 |
| 每2小時增量記憶蒸餾 | 兩筆都跑 → 記憶蒸餾做兩遍（浪費算力，可能重複寫入）|
| 每4小時主動關懷 | 一筆 announce 一筆靜默 → 多跑一次 |
| 📚 結繩領導學閱讀提醒 | 一 announce 一靜默 |
| 執董週會提醒 / 信貸繳款提醒 | 一 announce 一靜默 |

**根因**：多半是每筆排程被建立成「一個帶 model、一個不帶 model」的兩份（設定遷移或重複註冊留下的孤兒）。
**建議**：每組保留「有 announce + 有 model」那筆，刪掉雙胞胎。刪 cron 有副作用（怕刪錯），**待教練說「清」我再一組一組刪並附刪除憑證**。
