# 模型分工規則：三個燈號（🔵 Haiku／🟢 Sonnet／🟣 Opus）

> v3（2026-10-09 教練親定）：在 Sonnet／Opus 兩級之外多一個 🔵 Haiku 級。
> 教練原話：「我已經寫成 SOP、在我們系統中屬於常態性的東西……這些都是固定的 SOP 動作，是不是可以請你都歸類為 Haiku 可以處理？」
> 「每一個任務請你先評估我的指令，決定由哪一個模型來做並亮燈顯示。以前綠燈是 Sonnet、紫色是 Opus，現在可能要再多亮一個藍色燈號代表 Haiku 能做。」
> v1/v2（2026-09-25）原話：「重大決策時我會請 Opus 出來，平常一般的庶務類雜事我還是讓 Sonnet 解決。」「該用 Opus 就用，該省就省。」
> 機制：`scripts/model_tier_advisor.sh`（UserPromptSubmit hook）每句話注入提醒；`scripts/stop_rules_master.py` A3 檢查回覆有沒有亮燈。
> 檔名保留舊名（很多地方引用），內容以本檔為準。

## 🔵 Haiku 級：已經寫成 SOP 的固定動作
照現成 SOP／腳本一步一步做，不需要判斷新方向。教練點名的：
1. **更新戰報、戰情儀表板**（每週來賓／1對1／咖啡數據）
2. **簡報套版**（BNI PPT SOP、簡報套底圖）
3. **上架**：策展 SOP（店家）、大樹作品上架 SOP（教練個人創作）
4. **名單異動**：新增籌備會名單、正式例會名單
5. **控制電腦照步驟查／填**：去行事曆（Calendar）搜尋資料、開發票（ezPay）
6. 其他同類：查名片、查發票紀錄、開工回報、分類／標籤／摘要／從檔案抓資料、簡單問答、閒聊

🔴 **Haiku 級的前提是「照 SOP 走得通」**。下面任一種情況，當場升級，不要硬做：
- SOP 跑出錯誤、結果跟預期不同、要自己想新做法 → 升 🟢
- 同一件事修過又壞、要找原因、牽涉多個系統、不可逆（刪除、搬遷、花錢） → 升 🟣
- 教練不滿或第二次提同一件事 → 升 🟣

## 🟢 Sonnet 級：明確但沒有現成 SOP 的日常工作
日常寫作與改寫、一般寫程式、小修網頁、文件分析、照教練明確指示做單一新任務、收工總結（要判斷記憶與接力棒）。

## 🟣 Opus 級（符合任一條）
1. **找根因**：故障原因不明、修過又復發、已經繞兩輪還沒解決、教練問「為什麼只有X會」
2. **牽涉多個系統**：小龍蝦／赫米斯／網站／VPS／launchd／git 之間互相影響
3. **不可逆或影響大**：刪除、搬遷、架構改動、金鑰安全、花錢
4. **設計機制**：新規則、新 SOP、防呆 hook、從根源改流程
5. **教練已經不滿**：第二次提同一件事、「浪費時間」「繞一大圈」「又犯」
6. **重要對外內容**：代表教練對外的文案、提案、給別人看的報告

## 亮燈怎麼寫
**每一則交辦（≥15字，含天馬行空的新點子），不管現在哪個模型，回覆第一行一定亮燈：**
- 「🔵 這件 Haiku 就能做」
- 「🟢 這件 Sonnet 就能做」
- 「🟣 這件是 Opus 等級（理由：…）」
- 閒聊、道謝寫「🔵 閒聊」

## 亮燈之後怎麼做（「目前模型」以系統提示寫的為準，hook 顯示的只是參考）
| 目前模型 | 任務是 🔵 | 任務是 🟢 | 任務是 🟣 |
|---|---|---|---|
| **Haiku** | 照常做 | 只加一句「教練，建議切換到 Sonnet 5.5 再做；要用目前模型直接做，回『直接做』」，先不動手 | 只加一句「教練，建議切換到 Opus 5.5 再做，可能會節省您的時間；要用目前模型直接做，回『直接做』」，先不動手 |
| **Sonnet** | 照常做完，第一行補「下一件可以切到 Haiku 省流量」 | 照常做 | 同上，建議切 Opus，先不動手 |
| **Opus** | 照常做完，第一行補「下一件可以切到 Haiku 省流量」 | 照常做完，第一行補「下一件可以切回 Sonnet 省流量」 | 照常做 |

- 教練說「直接做」：用目前模型照常做。
- **做到一半卡關**（兩種方法都沒解決、找不到原因，或教練說「還是不行」）：立刻停下，說「教練，我卡關了，建議切換到 ○○ 接手」＋卡在哪一句。Haiku 卡關建議 Sonnet；要找根因就直接建議 Opus。Sonnet 卡關建議 Opus。

## 為什麼「目前模型」不靠 hook 判斷（2026-10-09 查證）
教練在送出訊息前用 `/model` 切換時，切換紀錄寫進對話檔的時間比 hook 執行還晚，hook 讀檔只看得到上一則回覆的模型（10/09 切到 Opus 後 hook 仍顯示 haiku）。回覆的模型從系統提示一定知道自己是誰，所以由它判斷。hook 會把收到的輸入欄位存在 `state/model_tier_advisor_last_input.json`，日後 Claude Code 若直接提供模型欄位，hook 會優先使用。
