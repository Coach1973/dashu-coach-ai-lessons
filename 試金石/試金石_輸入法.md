## 📍 案例 001：鼠鬚管不斷重複註冊（4 個鼠鬚管）

**嚴重程度：** 🔴 常見

### 錯誤描述
每次打開 Squirrel.app，ABC 選單就多一個鼠鬚管，累積到 4 個，無法刪乾淨。

### 根因分析
macOS 不會自動刪除舊的輸入源，每次 Squirrel.app 部署都會重新註冊，疊加上去。

### 正確做法
**第一步（手動）：** 系統設定 → 鍵盤 → 輸入來源 → 刪除多餘的鼠鬚管，只留 1 個

**第二步（軍師執行）：**
```bash
# 1. 備份
cp -r ~/Library/Rime ~/Library/Rime/_backup_$(date +%Y%m%d_%H%M%S)

# 2. 清理舊 build 產物
rm -rf ~/Library/Rime/build/*

# 3. 重新部署
open -a Squirrel

# 4. 等 10 秒，確認有 .bin 生成
sleep 10 && ls ~/Library/Rime/build/*.bin | wc -l
# 結果應 > 0

# 5. 驗證只有 1 個鼠鬚管
defaults read ~/Library/Preferences/com.apple.HIToolbox.plist \
  AppleEnabledInputSources | grep -c "Squirrel"
# 結果應為 2（Squirrel Hant + Hans）
```

### 預防措施
不要頻繁打開 Squirrel.app，平常用 `Ctrl+Space` 切換即可。

### NEC（下次遇到）
1. ABC 出現多個鼠鬚管 → 系統設定刪多餘的
2. 之後需要部署時 → 備份 → 清理 build → 重新部署
3. commit hash：`f2448c85`

## 📍 案例 002：plist 操作搞反導致 0 byte（嚴重失誤）

**嚴重程度：** 🔴 最高緊急

### 錯誤描述
Python `plistlib.dump` 用錯簽名，`HIToolbox.plist` 變成 0 byte，教練差點失去所有輸入法。

### 根因分析
簽名格式搞反，導致檔案被覆蓋成空白。沒有先備份。

### 正確做法
**寫入前（必做）：**
```bash
# 永遠先備份
cp ~/Library/Preferences/com.apple.HIToolbox.plist \
   ~/Library/Preferences/com.apple.HIToolbox.plist.bak
```

**寫入後（必做）：**
```bash
# 立刻驗證
defaults read ~/Library/Preferences/com.apple.HIToolbox.plist | head -5
# 若顯示 "does not exist" → 立刻還原
cp ~/Library/Preferences/com.apple.HIToolbox.plist.bak \
   ~/Library/Preferences/com.apple.HIToolbox.plist
killall cfprefsd
```

### 預防措施
任何危險操作（plist、系統偏好設定）都要先 `cp` 備份，寫完立刻 `defaults read` 驗證。

### NEC（下次遇到）
1. 要寫入 plist → 先 `cp` 備份
2. 寫完 → `defaults read` 立刻驗證
3. 發現問題 → 立刻還原 `.bak`
4. 寫入危險操作段進記憶

## 📍 案例 003：OpenVanilla 香草輸入法導致 E/F/I/M 快捷鍵失效

**嚴重程度：** 🟡 中

### 錯誤描述
在語音輸入法模式下，輸入 E、F、I、M 會觸發系統快捷鍵，而不是正常打字。

### 根因分析
OpenVanilla 的 liu7（嘸蝦米）模式下，E/F/I/M 被設為特殊功能鍵（叫出符號、放大候選、搜尋字根等）。

### 正確做法
1. 打開 OpenVanilla 偏好設定
2. 找到 E/F/I/M 對應的快捷鍵設定
3. 將這些快捷鍵取消或改為不觸發
4. 或者：移除 OpenVanilla（已改用鼠鬚管）

### NEC（下次遇到）
1. E/F/I/M 亂觸發快捷鍵 → 檢查是否在 liu7 模式
2. 若要移除 OpenVanilla → 先確認鼠鬚管已正常工作
3. commit：已完整卸載 Boshiamy，`3e3c21eb`

## 📍 案例 004：鼠鬚管看不到 liur schema（部署後輸入法沒出現）

**嚴重程度：** 🟡 中

### 錯誤描述
執行 `open -a Squirrel` 後，系統設定裡還是沒有鼠鬚管。

### 根因分析
`cfprefsd` 或 `TextInputMenuAgent` 需要重啟才能讀到新的輸入源註冊。

### 正確做法
```bash
# 強制重啟相關 daemon
killall cfprefsd
killall TextInputMenuAgent
killall Squirrel
open -a Squirrel
# 等待 5 秒
```

### NEC（下次遇到）
1. 部署完但輸入法沒出現 → `killall cfprefsd && open -a Squirrel`
2. 若還是沒有 → 重開系統設定
