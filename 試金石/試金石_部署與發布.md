## 📍 案例 001：Netlify 部署鐵律（最高優先）

**嚴重程度：** 🔴 最高優先

### 錯誤描述
未經教練確認就推送、連續推修小問題、浪費 Netlify 部署次數。80 次不成熟部署燒掉 1200 點（每次 15 點），帳號已超用。

### 根因分析
沒有標準流程，每次部署都是「試了再說」。沒有先讓教練確認的步驟。

### 正確做法（SOP 七步驟）

**第一步：下載與整理**
```bash
mkdir -p /tmp/deploy_website && cd /tmp/deploy_website
# 把所有 HTML + 圖片 + _headers 全部整理好
```

**第二步：處理 _headers**
```
# /tmp/deploy_website/_headers
/*
  Cache-Control: no-cache
  X-Frame-Options: SAMEORIGIN
```

**第三步：本機預覽**
```bash
# 用本地 HTTP server 預覽（不走 localhost）
cd /tmp/deploy_website && python3 -m http.server 8080
# 或打開瀏覽器直接 open index.html
```

**第四步：教練視覺確認**
軍師用 `open` 指令開瀏覽器讓教練親眼看，**不只用語言描述**。

**第五步：教練說「推」或「沒問題」**

**第六步：一次性推送**
```bash
# 走 GitHub Pages（免費）
cd /tmp/deploy_website && \
zip -r deploy.zip . && \
curl -X POST \
  -H "Authorization: Bearer $NETLIFY_TOKEN" \
  -F "file=@deploy.zip" \
  "https://api.netlify.com/api/v1/sites/$NETLIFY_SITE_ID/deploys"
# 或用 git push 到 GitHub Pages 分支
```

**第七步：驗證**
瀏覽器打開網址，確認所有內容正常顯示。

### 預防措施
永遠不走「試了再看」的模式。要先讓教練確認，再行動。

### NEC（下次遇到）
1. 任何網站部署需求 → 問「要在哪個平台？」
2. 若選 Netlify → 走 GitHub Pages 主線，Netlify 只做最終同步
3. 若選 GitHub Pages → 直接 push 到 `gh-pages` 分支
4. **禁止**：未經教練確認就推送

## 📍 案例 002：HTML 預覽不走 localhost（軍師端 Chrome MCP 指向錯誤）

**嚴重程度：** 🟠 高

### 錯誤描述
軍師用 Chrome MCP 打開 `http://localhost:端口/`，以為 HTML 沒問題，但教練那邊看不到。

### 根因分析
軍師端 Chrome MCP 連的是教練 Windows 機的 Chrome，不是 Mac 本機，所以看不到 Mac localhost。

### 正確做法
1. **確定 MCP 指向哪台機器**：先問「我的 Chrome 連的是哪台？」
2. **若要本地預覽**：用 `python3 -m http.server` 讓教練自己打開
3. **若要遠端預覽**：走 GitHub Pages 或 VPS 上的 HTTP server
4. **不要假設**：自己能從瀏覽器看到 Mac localhost

### NEC（下次遇到）
1. 需要預覽 HTML → 問「教練，請問您是在 Mac 還是 Windows？」
2. 走 GitHub Pages（`coach1973.github.io/`）最安全
3. commit：`5eec01dd`（首次記錄）

## 📍 案例 003：圖片從 Netlify 舊版救回（備份策略）

**嚴重程度：** 🟡 中

### 錯誤描述
northern-tw.netlify.app 圖片全部 404，因為相對路徑圖片沒有一起上傳到 GitHub。

### 根因分析
Netlify 舊版的圖片是上傳到 Netlify 雲端，移到 GitHub Pages 時這些本地檔案不在 repo 裡。

### 正確做法
1. **從 Netlify 舊版 deploy 紀錄下載**：
   - 進 Netlify → Deploys → 找舊版 deploy → Download file
2. **把圖片放回正確資料夾**
3. **確認 repo 有 commit**

### NEC（下次遇到）
1. 圖片 404 → 先問「之前是在 Netlify 還是 GitHub？」
2. 若在 Netlify → 去 Netlify 舊版 deploy 找
3. 救出來 → 放 repo → commit
