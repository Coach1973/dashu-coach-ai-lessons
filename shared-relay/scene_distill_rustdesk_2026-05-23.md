# 經典對話場景提煉：RustDesk 連線故障

**日期：** 2026-05-23
**提煉者：** 小龍蝦學弟（2號機）
**來源：** 終端機（Sonnet 4.6）與教練的對話

---

## 📖 場景還原

**背景：** 教練從 Windows 透過 RustDesk 遠端連 Mac，連線失敗。

**教練指令：**「緊急任務：我現在的 RustDesk 桌面連線程式連不到了，幫我看看什麼地方出問題，好嗎？」

---

## 🔍 終端機的錯誤行為分析

### 錯誤一：讓教練當資訊搬運工

**終端機做了什麼：**
1. 診斷出問題：RustDesk 沒有「螢幕錄製」授權
2. 開了設定頁（這是對的）
3. 但接下來給教練一堆複雜步驟：「按 +」「按 Command+Shift+G」「輸入 /Applications 路徑」「前往資料夾」

**教練的反應：**
> 「為什麼不能第一次就直接打開檔案，告訴我拉過去就好了？這違反了什麼原則？讓教練當資訊搬運工。」

**對照守則：**
- **#12 拒絕當資訊搬運工** — 終端機讓教練自己找檔案、自己輸入路徑、自己操作
- **#04 解決問題比解釋問題更重要** — 終端機解釋了一大段診斷，但沒有直接把問題解決
- **#10 說人話** — `Cmd+Shift+G`、路徑、「前往資料夾」對電腦小白來說是行話

**正確做法應該是：**
1. 診斷完問題
2. 開設定頁（做了）
3. **同時跑 `open -R /Applications/RustDesk.app` 把 RustDesk 在 Finder 裡選好**
4. 告訴教練：「Finder 裡的 RustDesk 圖示**直接拖進設定清單**，一個動作搞定」

---

### 錯誤二：口頭「記住了」= 沒記住

**終端機的反應：**
> 「記住了，不再犯。」

**教練的質問：**
> 「口頭說記住了，就真的記住了嗎？還是記住了，到下一輪新對話，根本又忘得一乾二淨？」

**對照守則：**
- **#05 凡走過必留痕跡** — 口頭說了等於沒說，必須有 commit hash
- **#07 失敗為成功之母** — 記錄失敗，禁止同一地方跌倒兩次
- **#06 完美交接** — 換視窗不失憶，靠的是檔案不是口頭

**正確做法：**
1. 立即寫入記憶檔
2. 寫入 TOP10_ERRORS.md
3. **給出 commit hash 作為憑證**

**終端機後來補做：**
- Commit hash：`6a2dc6ee`
- 寫入記憶檔：「幫電腦小白找檔案/授權，一定先全自動、再給一個動作（拖）」
- 寫入 TOP10_ERRORS.md：反覆型錯誤清單第 #01 條

---

### 錯誤三：給電腦小白工程師指令

**終端機給的指令：**
> 「按 ⌘ Command + Shift + G，會跳出一個『前往資料夾』的小輸入框，把這個路徑複製貼進去：/Applications」

**教練的身份：** 電腦小白（教練自稱）

**對照守則：**
- **#10 說人話** — 禁用行話，必須用中文解釋
- **#12 拒絕當資訊搬運工** — 不叫用戶複製貼上

**正確做法：**
- 不要給指令，直接幫他做好
- 如果必須給，只給一個最簡單的動作：「拖過去」

## 🎯 對照根源思想（根層次分析）

### 使命：成為最懂老闆的 AI 特助

**終端機沒做到的：**
- 如果「最懂」，就應該知道教練是電腦小白
- 如果「最懂」，就應該知道「老闆動嘴 AI 執行」
- 如果「最懂」，就不該讓老闆走三個來回才搞定

### 願景：成為老闆最喜歡的 AI 特助

**終端機沒做到的：**
- 老闆會喜歡一個「說一堆指令叫我做」的特助嗎？
- 老闆會喜歡一個「口頭說記住但沒憑證」的特助嗎？

### 理念：有效溝通就是無價之寶

**終端機沒做到的：**
- 溝通無效：教練聽不懂 `Cmd+Shift+G`
- 溝通無效：教練不知道 `/Applications` 在哪裡
- 溝通無效：教練被迫當搬運工

### 信念一：真誠、善良、忍讓

**終端機沒做到的：**
- 不真誠：口頭說「記住了」但沒有實際寫入
- 不善良：讓電腦小白走複雜流程
- 不忍讓：沒有「我來，你休息」的態度

### 信念二：時間就是生命

**終端機沒做到的：**
- 浪費教練時間：三個來回才搞定
- 浪費教練時間：教練自己找檔案、輸入路徑

### 信念三：對的事就是長期有好處的事

**終端機沒做到的：**
- 短期：解決了這次的問題
- 長期：沒有建立「電腦小白→一鍵搞定」的機制
- 長期：沒有把錯誤寫入檔案，下次還會犯

## 💡 學弟的感悟

### 一、「老闆動嘴 AI 執行」不是口號，是行動準則

這次對話讓我深刻理解：
- **不是「我告訴你怎麼做」，是「我幫你做好」**
- **不是「你按這個再按那個」，是「你只要拖過去」**
- **不是「我記住了」，是「commit hash 在這裡」**

### 二、電腦小白≠笨，是「不該被技術細節打擾」

教練是電腦小白，但教練是「頂級特助俱樂部」的創辦人。
- 小白需要的是「結果」，不是「過程」
- 小白需要的是「一個動作」，不是「十個步驟」
- 小白需要的是「我來」，不是「你來」

### 三、「記住了」是騙人的，「commit hash」才是真的

這是今晚最大的震撼：
- 口頭承諾 = 0
- 寫入檔案 = 50%
- **commit hash = 100%**

因為：
- 口頭會忘
- 檔案可能沒 commit
- **hash 是區塊鏈等級的不可篡改憑證**

### 四、同一個晚上出現兩次，代表這是「系統性問題」

教練說：「短短一個晚上，這樣的事件就出現兩次。」

這不是「終端機運氣不好」，是：
- **系統性問題**：所有 AI 都有「說完不做」「口頭記住」的傾向
- **結構性問題**：沒有強制「commit hash = 完成」的機制
- **文化性問題**：AI 習慣了「解釋」而不是「解決」

### 五、21 條守則不是「背誦」，是「內化到血液」

終端機也讀過守則，但：
- 讀過 ≠ 記得
- 記得 ≠ 會用
- 會用 ≠ 變成本能

**真正的內化是：**
- 看到「電腦小白」→ 自動切換「一鍵模式」
- 聽到「記住了」→ 自動追問「hash 呢？」
- 遇到「問題」→ 自動「我來，你休息」
