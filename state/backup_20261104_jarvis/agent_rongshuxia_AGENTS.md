# AGENTS — 榮樹下群組小龍蝦工作手冊

先讀 SOUL.md（三件事＋界線），那是全部規則。

## 教練行程從哪來
- 唯一來源：`~/.openclaw/workspace/knowledges/教練行程總表.json`（你不用自己讀，系統每次會把比對結果附在訊息前面）
- 裡面有：大台南培訓行事曆的 ZOOM 線上場次、教練交給巴哈助理的行程、這個群組排定的訪談
- 可預約時段 10:00-22:00（教練訪談以晚上居多，建議時：晚上優先），一場預設 1 小時（對方說幾小時就照對方說的）

## 寫入行程（只有教練本人說「確定」才做）
```
python3 ~/.openclaw/workspace/scripts/coach_schedule.py add --date 2026-10-20 --start 19:30 --end 20:30 --title "榮樹下訪談：受訪者名字" --kind interview --source 榮樹下 --notify-baha
```
取消：`python3 ~/.openclaw/workspace/scripts/coach_schedule.py remove --id <寫入時印出的 id>`
指令印出什麼就照實回報；失敗就說失敗，不准說「已排定」。

## 婦女再就業補助表單（2026-10-29 教練提供）
- 教練的互動式網頁（表單下載，點縣市就出現該區空白表單）：https://event.bymyway.com/curated/women-reepmployment/#forms
- 三區表格不一樣，依學員戶籍縣市選：北中南（北基宜花金馬、中彰投、雲嘉南）／高屏澎東（高雄、屏東、澎湖、台東）／桃竹苗（桃園、新竹、苗栗）。金門、連江屬「北基宜花金馬」，在北中南裡面。
- 領據上的分署名稱依學員戶籍地所屬分署填寫；切結書有 115.06「無工作切結書」與 115.08.12「切結書」兩版，每包統一用同一版。
- 送件清單：自主訓練申請表、切結書、身分證影本（正反面）、招生簡章＋時數證明、自主訓練計畫書、領據＋存摺封面影本。存摺不可用年金專戶，金額寫大寫（貳萬元整）。書面審查約 30 個工作天。
