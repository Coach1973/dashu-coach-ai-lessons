# 任務：「軍火庫」總入口＋入選卡 設計稿（大樹教練 2026-10-16 交辦）

你在 Coach1973/rongtree 倉庫。注意：這次不是改榮樹下網站，只是借這個倉庫放一份**設計稿**。榮樹下是大樹教練（吳大樹）的 Podcast 品牌，正式網址 https://event.bymyway.com/curated/rongtree/ ，它的 index.html 是這次要參考的「視覺語言」和「百集格子」做法。

## 這份設計稿要解決什麼
大樹教練手上有四群人：BNI 商務夥伴、AI 導師、公益企業家、志工。過去他們彼此看不見。我們要做一個對外的總入口，叫「軍火庫」，讓外面的人「一眼看出這裡有多少強者」，也找得到對的人。
- 主標（暫定）：**你要的資源，這裡找得到**
- 副標（暫定）：**你的優秀與想法，也會在這裡被看見**
- 一句話：需求的人找得到資源（需求端）；有本事的人被看見（供給端）。兩邊都在同一頁才是平台。
- 7 天衝刺目標（暫定，只用在設計稿的示範數字）：對外喊 200 位，進度每天看得到在漲。

## 最重要的規定
- 只能在分支 `claude/arsenal-entry-design` 上工作和推送。**絕對不要推 main、不要開 PR、不要合併。**（榮樹下 main 一推上去，正式網站就會自動換新。）
- 只新增資料夾 `arsenal-design/`（內含 `index.html`）和一封信 `docs/to_junshi/2026-10-16_arsenal_entry_design.md`。**不要改倉庫裡任何現有檔案**（index.html、interview-flow.html、invite.html、volunteer.html、wang-dm.html、pledges.json、img/ 都不動）。
- 不能改伺服器，雲端也連不到教練的 Mac 與正式資料。所以：**所有人名、照片、數字一律用「示範」資料**，頁面最上方要有一條清楚的「設計稿 ‧ 示範資料」提示。不要放任何真人姓名、照片、電話、LINE。
- 全部繁體中文、白話。**網頁上所有字最小 20px**（教練規定，任何 font-size 或 font 簡寫都不能小於 20px，頁尾也一樣）。
- 對外版：**不放 BNI 商標，也不寫 BNI 分會名義**，只說「我們的夥伴」。不寫「全台最大」「全台紀錄」這類沒辦法證明的話，只用數字說話（真誠原則）。不要特別強調中國大陸（教練團隊重心在台灣）。
- 單一檔案：`arsenal-design/index.html`，CSS、JS 都寫在裡面，不依賴外部 CDN 腳本（字型可用 Google Fonts，連不到時要有替代字型）。不要引用 `/static/` 之類 Mac 伺服器上的檔案。
- 視覺語言沿用榮樹下 `index.html`（色彩、字型、圓角、金色強調的做法），看起來是同一個品牌家族，但這是「總入口」，氣勢要比榮樹下更大、更像一面牆。

## 頁面要有的東西（照這個順序，設計細節你自己做決定）

1. **首屏**：主標、副標、**即時人數計數器**（例：已集結 ○ 位／目標 200，示範數字）、兩個最大的按鈕：「找資源」（捲到搜尋區）和「我也想被看見」（捲到加入區）。每一頁只放一個最大的按鈕，對準下一步。
2. **找資源**：
   - 搜尋框（可搜姓名、領域、一句話）。
   - 「用能幫你解決什麼」分類，不是用職稱。真 AI 導師席的 8 大領域是：搜尋行銷、媒體曝光、在地行銷、資本與商業模式、數位轉型、協會與政府補助、AI 落地、音樂藝文。公益領域先用你自己想的一組示範分類，並在信裡註明「待軍師換成真公益 9 大領域」。
   - 「臉」篩選：全部／真 AI／真公益／榮樹下嘉賓／志工。**同一個人可以同時有好幾張臉（標籤）**，篩選只是換看法，不是複製資料。
   - 結果顯示成人物卡（示範）：席次編號、姓名（示範夥伴 01…）、領域、一句話、臉的標籤，以及最顯眼的按鈕「請大樹團隊幫我引薦」（這個按鈕要經過我們，不是直接給電話；設計稿只要做到按下去有回饋）。
3. **席次牆（最像「秀肌肉」的地方）**：No.001～No.100 的「創始席」格子，做法參考榮樹下 `index.html` 的 1～100 格子（已亮的金色、空的寫「等你」）。已入席的格子亮起，點一下看那位的卡片；空格寫「等你」，點了帶到加入區。手機上格子要好按（最小 44×44px 以上）。示範資料請讓大約 30～40 格亮起，看起來有氣勢但不是假裝已經滿了。
4. **許願池**：標題大意「說出你要找什麼」。一個輸入框＋送出。這是整頁的需求端，會累積成「大家在找什麼」的清單。設計稿請在頁面上放 3～5 則**示範**許願（例：想找短影音團隊、想找 AI 導入顧問），讓人看到池子是活的。
   - 送出後的真實動作是呼叫 `/api/works/contact`（教練 Mac 上的伺服器，會把訊息送進「活動報名即時通知」群）。參考倉庫 `index.html` 裡「預約合作」表單怎麼呼叫它，**欄位格式照抄**。
   - **設計稿階段不要真的送出**：用一個寫在 script 最上面的 `const DEMO = true;`，DEMO 時只在畫面顯示「已收到（示範）」；`DEMO = false` 時才打 API。這樣軍師在 Mac 上預覽不會誤發真通知。
5. **入選卡（可分享的卡）**：「我入選了大樹軍火庫 No.0XX」。做出 3 張不同領域的示範卡，直式（約 4:5）、字大、一眼看得懂：席次編號、姓名（示範）、領域、一句話、一個「分享」按鈕（設計稿用 Web Share API 失敗就複製網址的做法，失敗要有提示）。旁邊用 3 步講「怎麼拿到自己的卡」：被提名→按「我同意上架」→領卡分享。
6. **加入區（我也想被看見）**：5 分鐘填完的簡短表單示意（姓名、領域、一句話、要公開的連結、勾選「我同意上架」）。同樣 DEMO 時不送出。
7. **關係階梯**（小一點，放在加入區附近）：路人→被看見→連結→合作→加入，一行帶過，讓人知道下一步。
8. **頁尾**：「本頁為設計稿，資料皆為示範」＋聯絡方式沿用榮樹下頁尾的寫法即可（不要新增真實聯絡方式）。

## 資料要寫成「可以換成真資料」的形狀
頁面上的人物、計數器、許願，全部從 script 最上面的常數畫出來，之後軍師會把它換成真名冊的 API。請你定義清楚的資料形狀，並在信裡原樣貼出來：
- `ROSTER`：每人一筆，至少有 `no`（席次編號）、`name`、`faces`（陣列，例 `['ai','charity']`）、`domains`（陣列）、`line`（一句話）、`consent`（是否同意公開，只有 true 才畫出來）。
- `COUNTERS`：`joined`、`goal`、`wishes`、`introductions`。
- `WISHES`：示範許願清單。
這是為了讓之後的「名冊引擎」（一份名冊多張臉）可以直接接上；你的設計就是它的第一個畫面。

## 版面與驗證要求
- 手機寬 400px 和桌機寬 1440px 都要好看；平板 1024px 與小手機 360px 也要不壞。頁面不能左右多出來可以橫向滑動。
- 雲端連不到正式網站，請像做榮樹下那次一樣，自己用 Playwright 的 Chromium 開頁測試。至少自動檢查：沒有 JavaScript 錯誤；所有字 ≥ 20px（也掃 CSS 原始碼，沒有任何小於 20px 的 font-size 或 font 簡寫）；所有 `#` 連結都找得到位置；格子剛好 100 格、編號 1～100 照順序；手機上可點的東西 ≥ 44px；`DEMO = true` 時送出表單不會發出任何對外網路請求。
- 請自己看截圖（桌機、手機 400、小手機 360、平板），看到問題就修，再交。
