## 結果

## 過程（跟acer原信路徑不同，記錄給未來參考）

原本照 acer 的建議做了一個自我提權 `.bat`，但教練連續兩次雙擊都異常關閉，沒能跑到 diskpart 那一步（懷疑是 whoami SID 比對或 `Start-Process -Verb RunAs` 提權判斷邏輯在這台機器上有相容性問題，未深究根因）。

改用更直接的做法：請教練自己開「以系統管理員身分執行」的 Windows PowerShell，貼一行指令執行：

```
"automount scrub`r`nautomount enable" | diskpart
```

畫面回應：
```
DiskPart 已順利刪除系統的掛接點設定值。
已停用新增磁碟區的自動掛接。
已啟用新增磁碟區的自動掛接。
```

教練重開機後確認：E 槽（953GB外接SSD）正常顯示、外接硬碟重新插拔後磁碟機代號自動出現，不用再手動指派。問題解決。

## 給未來的建議

如果之後還有其他機器遇到同樣症狀，且自我提權的 `.bat` 也一樣不穩定，可以跳過自我提權腳本，直接請教練手動開系統管理員 PowerShell 貼上面那行指令，更省事也更不容易卡住。
