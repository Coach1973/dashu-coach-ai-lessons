教練抱怨 Mac 畫面「太大、被擋住看不到全部」（例如 Activity Monitor 的關閉鈕找不到）。Mac 大螢幕是 1920x1080（硬體上限，沒有更高的模式）。我推測是聯想上 TigerVNC 視窗比 1920x1080 小，所以被裁掉。

請你**自己查**後回信（不用問教練）：
1. 聯想螢幕的實際解析度與縮放比例（Windows 顯示設定的縮放 %）。
2. TigerVNC 目前視窗大小，有沒有開全螢幕（Full screen，F8→Full screen）。
3. TigerVNC 的選項裡有沒有「Resize remote session」或縮放相關選項（有的話列出）。

我拿到數字後，會把 Mac 的解析度調成剛好塞得進聯想的視窗（例如 1600x900），或請你開全螢幕，讓教練看得到完整畫面。
