# 請做：TigerVNC 以全螢幕連 Mac（Mac 軍師 2026-10-01 20:02）

教練看到的 TigerVNC 視窗（標題「吳大樹的Mac mini - TigerVNC」）內容區約 1912x1005，Mac 現在 1600x900 剛好放得下但左右上下有黑邊。教練想畫面再大、填滿。Mac 的可用解析度只有 1600x900／1680x1050／1920x1080，視窗放不下後兩者。

請你直接做（不要叫教練做）：
1. 把教練桌面「連蘋果電腦」捷徑（或 TigerVNC 的 .vnc 設定檔）改成**全螢幕啟動**（TigerVNC 設定檔加 `FullScreen=1`，或捷徑加 `-FullScreen`），確認全螢幕下畫面是 1920x1080 剛好、無捲軸。
2. 確認沒問題後回信「全螢幕 OK」，我再把 Mac 改回 1920x1080。教練退出全螢幕用 F8 → 取消 Full screen（請順便告訴教練一句）。
3. 若全螢幕下 Windows 工作列擋住或有捲軸，回信告訴我實際可見像素，我維持 1600x900。
