## Q2：怎麼避免副作用1（欄位互相清空）？找到真正根因了

我這邊測了3種操作方式（真人點擊打開下拉又按Esc不選、直接用JS改eventType的value、直接呼叫getDataOnRegion()函式），**都無法重現「click活動類型會清空地區」這個現象本身**——地區欄位在我這邊每次測試後都還是穩穩停在`23268`。

但我測出了一個更根本、能完整解釋你觀察到的現象的東西：

**`getDataOnRegion()`（地區欄位觸發的函式）是非同步的（會打AJAX去後端抓「這個地區底下有哪些聯絡人/場所/活動類型可選」），完成後會把 `eventTypeSelect`、`eventContactPerson`、`eventLocation` 這三個下拉選單的選項清單整個換掉，瀏覽器換選項清單時如果原本選到的值不在新清單裡（或AJAX還沒回來前你選的值），就會自動重置回清單第一個選項。**

我實測：呼叫`getDataOnRegion()`前我先把活動類型設成「領導團隊培訓」(value=2)，呼叫後等0.8秒再檢查，活動類型**被reset回`660`（BNI台灣會員大會，清單第一個）**——跟你觀察到「活動類型互動後地區出狀況」是同一種「非同步回來把你剛設的值蓋掉」的現象，只是蓋掉的欄位方向可能因為你操作的時間點/順序不同而不同。

**結論／正確做法**：
1. 先選地區「大台南南區」
2. **等待至少1秒，讓 `getDataOnRegion()` 的AJAX真的跑完**（不要用「點完馬上做下一步」的節奏，這是純非同步race condition，跟你用什麼工具點擊無關）
3. 確認等待夠久之後，**才**依序設「活動類型」→「聯絡人」→「場所」
4. 這三個全部設定完，再填名稱/日期/時間/費用/人數
5. 最後才提交

如果你的工具可以偵測「聯絡人下拉選單的選項清單已經變化」再繼續，那是最保險的判斷完成時機的方法（比固定等1秒更可靠）；沒有這種偵測能力的話，抓保守一點等1.5～2秒再繼續操作，這個表單沒有明顯的loading動畫可以肉眼判斷。

我原本14:50那封SOP信只提到「聯絡人/場所會被reset」，漏了「活動類型也會被reset」——這是我沒測完整，已經補在這封信裡，抱歉造成你卡住。
