## 1. 資料來源

原始檔案：`~/Downloads/__-__-__-___31-08-2026_3-04_PM.xls`（5.8MB，SpreadsheetML格式的XML，不是真正的二進位xlsx，副檔名雖是.xls但是文字XML檔，可以直接用Python `xml.etree.ElementTree`或Node.js的XML parser讀，不需要`xlsx`套件）。這是BNI Connect官方「地區-查看來賓」報表，範圍2018-08-08~2026-09-01（8年），共**3718筆來賓造訪紀錄**。

**表格結構**（前10列是報表頁首/參數，第11列（index 10）才是欄位標題列，第12列起才是資料）：
```
欄位標題列: 姓氏, 名字, 公司, 職業, 電子郵箱, 電話, 地址 第一行, 地址 第二行, 城市, 狀態, 郵政編碼, 國家, 分會, 訪問日期, Invited By, Type
```
範例資料列：
```
Nuril, Amin, UD. Keluarga, 家具維修/室內裝潢, 12345@gmail.com, 082245054556, ,, Magetan,,, JP, 真富, 2025-04-02T00:00:00, 許 瀅瀅, 第一次訪問
```

**已驗證過的關鍵欄位**：
- `訪問日期`：ISO格式日期時間字串（如`2025-04-02T00:00:00`），這是這筆「來賓造訪」發生的日期
- `Invited By`：邀請這位來賓的**會員姓名**（這是你要統計的主體，不是來賓本人）
- `分會`：這筆造訪所屬的分會（實測目前資料涵蓋5個分會：**真富、真愛、真誠、真鑫、真鑽**，跟`bni-chapters`系統的分會名稱一致）
- 一個會員（`Invited By`）可能有多筆紀錄（邀了很多來賓、或同一來賓來訪多次），你要做的是**依`Invited By`+`分會`分組，找出每個組合最近一次（MAX）的`訪問日期`**

軍師已經用Python驗證過：全部資料可以分組成**318個「(邀請人,分會)」組合**，每個組合都能算出最近一次邀約日期。

## 2. 計算邏輯（核心需求）

對每個「(邀請人,分會)」組合：
1. 找出該組合下所有紀錄的`訪問日期`，取最大值 = 「最近一次邀約日期」
2. 用「今天」減去這個日期，換算成經過幾個月
3. 教練要求可以用以下**13個門檻分開查詢**："多久沒邀約"：1、2、3、6、9、12、18、24、36、48、60、72、84個月

**做法比照培訓總覽既有邏輯**（你可以直接讀`Coach1973/BNI-Training`repo裡的`region_build_data.py`+`region_template.html`兩個檔案，那套系統是「後端Python算好資料寫進`data.json`（存原始日期，不是預先算好12種門檻），前端JS依使用者點的月數動態計算並即時重新渲染排行榜/名單，不用重新整理頁面」——這套架構直接套用即可，只是把門檻從培訓系統的（3/6/12/18/24/36/48/60）改成教練這次指定的13個（1/2/3/6/9/12/18/24/36/48/60/72/84）。

## 3. 公開頁面規格（比照現有培訓總覽風格，`https://coach1973.github.io/BNI-Training/`）

軍師已經看過這個頁面實際內容，結構是：
- 標題+時間範圍+統計摘要（幾筆紀錄、涵蓋哪幾個分會）
- 快速篩選按鈕列（近N個月，這次改成13個門檻）+ 自訂查詢輸入框
- 排行榜（這次應該反過來：**列出「最久沒邀約」的會員排行**，或教練要的「一目瞭然多久沒邀約」——建議做成類似培訓系統的「⚠️ 未參加培訓名單」概念，改成「⚠️ 超過所選門檻沒邀約來賓的會員名單」，由近到遠排序，直接顯示距今幾個月）
- 分會排名比較（各分會在所選期間內的邀約人次總量，可選配，非必要）
- 明細表（日期/會員姓名/來賓姓名/分會）

**🔴 隱私原則（務必遵守）**：現有培訓總覽公開頁**只顯示姓名/分會/日期/類型，完全不顯示電話/Email/地址**——這次來賓資料裡的電話/Email/地址/公司/職業等欄位屬於來賓本人的個資，**公開頁面一律不顯示**，只用姓名（邀請人姓名、可選配來賓姓名）+分會+日期，跟培訓總覽的揭露程度對齊，不要多顯示。
