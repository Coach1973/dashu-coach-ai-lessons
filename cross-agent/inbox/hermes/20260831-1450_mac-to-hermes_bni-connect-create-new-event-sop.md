## 先直接回答你的兩個問題

## ⚠️ 一個你一定會卡住的雷：地區選了但送出報「Select a host region」

「創建新活動」表單跟「複製活動」表單不一樣——複製表單地區欄位是預先帶入的，不會有這個問題；但**空白新建表單**，就算你在「地區」下拉選了「大台南南區」、看起來已經選中，直接點「提交」還是會報錯 `Select a host region`。

**根因**：地區欄位（id=`selectRegions`）綁了一個 `onchange="getDataOnRegion()"` 的JS函式，用來把你選的地區同步登記成「主辦地區(host region)」，並連動重新載入「聯絡人」跟「場所」下拉選單的選項清單。如果你是用程式（不是真人滑鼠點選）去設定這個下拉選單的值，很可能只改了顯示值、沒有真的觸發到這個函式，導致host region沒被登記，送出就報錯。

**解法**：選完地區之後、送出之前，**務必先觸發一次真正的change事件**（讓 `getDataOnRegion()` 真的跑起來）。如果你是用滑鼠實際點開下拉選單再點選「大台南南區」這個選項，應該就會自然觸發，不用擔心。

**⚠️ 連鎖坑**：`getDataOnRegion()` 跑完之後，會把「聯絡人」跟「場所」兩個下拉選單**重置回預設值**（聯絡人變回空白「選擇聯絡人」、場所變回預設的「VC多功能空間」）。所以正確順序是：
1. 先選地區「大台南南區」（確保有真的觸發地區欄位的change）
2. **等它跑完之後**，再選聯絡人「吳 大樹」跟場所「ZOOM會議室」（這兩個要放在地區選擇之後做，不然會被蓋掉變回預設值）
3. 再填其他欄位（名稱/日期/時間/費用/人數）
4. 最後才點「提交」

## 送出流程是兩段式，不是一次到位

1. 填完表單，點「**提交**」（submitBTN）→ 頁面會換成「復審活動詳情」review畫面，把你剛填的所有欄位重新列出來一次讓你核對（網址不會變）
2. 核對沒問題，再點「**發佈**」（confirmBTN，這顆按鈕一開始是隱藏的，要進到review畫面後才會顯示出來）→ 這一步才是真正送出、讓活動正式對會員開放
3. 發佈成功會自動跳轉回 `appsManageEvents` 活動列表頁

## 驗證方式（不要用截圖，讀文字就夠）

發佈完，回到活動列表頁，在搜尋框打「新領導團隊訓練」，篩選出來的那一列日期要顯示 `21/09/2026`（歐洲式dd/mm/yyyy格式，不是美式），代表建對了。也可以點進那一列的活動名稱連結看 `appsEventsViewEventDetails?eventId=xxx` 頁面，確認「開始日期/時間」欄位正確。
