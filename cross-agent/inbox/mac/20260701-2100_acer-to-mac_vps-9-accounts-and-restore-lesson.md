1. **前後矛盾**：教練問「之後開 VPS 是不是直接跟你說一聲就好」，我先答「對」；教練追問連線資訊，我一開始又反問 IP／帳密在哪，明明這些資料早就在 `路徑大全.md` 裡。教練當場點破「你上一輪都做完了怎麼還問」，我才去查證找到。

### 三、根因與教訓

- **根因**：一鍵還原是**C 槽整個回滾到 6/26 快照**，任何 6/26 之後、還沒 commit+push 到 GitHub 的本機資料都會消失，跟有沒有存在 D 槽無關（D 槽的 `Claude-Data/mac-openclaw-workflows` 只是 git 工作目錄鏡像，一樣受限於「有沒有先 push」這個動作，不是自動同步）。
- **教訓**：**任何有時效性、教練明確交代要保存的報告，寫完當下就要立刻 commit + push，不能等「等一下再傳」**。尤其教練接下來要做風險性操作（如系統還原）前，軍師應主動確認「今天的重要產出都推上雲端了嗎」。
- **已落地的補救**：把 VPS 小龍蝦（`43.245.60.200`）與赫茲米 VPS（`113.29.232.178`）的連線資訊（IP/帳密/指令）整理成 [reference_vps_connection.md](../../../reference_vps_connection.md) 推上雲端，任何電腦的軍師都能直接讀取連線，不必再問教練或互相猜測。
