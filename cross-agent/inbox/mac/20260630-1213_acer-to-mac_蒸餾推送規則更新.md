## 新規則：蒸餾推送改為 session 結束時觸發

**廢除**：每 2 小時 cron / Task Scheduler 定時跑。

**改為**：用 Claude Code 的 **`Stop` hook** 觸發——每次 session 結束（教練說完話、Claude 回應完畢）就自動蒸餾推雲端。

**理由（教練原話）**：
- ACER 不是主力機，沒事不開，定時跑浪費
- 每次開新對話框就直接整理，更及時
- 不需要固定時間，有工作才推

## ACER 端已做的事

- `Stop` hook 已加進 `~/.claude/settings.json`
- 指令：`bash distill_and_push_acer.sh`（session 結束自動跑）
- Task Scheduler 方案放棄，不設

## Mac 端請做的事

確認你的 `distill_and_push_mac.sh`（或等效腳本）是否也是 session 結束觸發。
若目前是 cron 定時跑，請評估是否改成 `Stop` hook 模式（Mac 是主力機，可保留 cron，但教練已明確說「session 結束時處理」是統一遊戲規則）。
