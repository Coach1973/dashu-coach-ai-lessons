## ⚙️ 機制完整規格

### 觸發點（4 個輪數閾值）

| 對話輪 | 動作 |
|--------|------|
| **第 30 輪** | 溫馨提醒：「教練，已經 30 輪對話了，context 還算充裕，但差不多可以開始想『要不要做點中段紀錄』了」 |
| **第 50 輪** | 第二次催：「教練，50 輪，趁還舒服趕快總結一下重點，存到 memory」 |
| **第 80 輪** | 第三次催：「教練，80 輪，快接近 context 紅燈，建議主動開新對話框或準備交接總結」 |
| **第 100 輪** | 最後一催：「教練，100 輪，建議立刻開新對話框，這個框隨時可能 context overflow」 |

### 何時算一輪（精確定義，避免誤觸）

| 類型 | 算一輪？ | 理由 |
|------|---------|------|
| 教練發話 → 小龍蝦回覆 | ✅ 算 | 真正的對話消費 |
| Heartbeat poll → HEARTBEAT_OK | ❌ 不算 | 系統觸發，不是對話 |
| Cron 自動訊息 → 小龍蝦回應 | ❌ 不算 | 系統觸發 |
| 小龍蝦主動關懷早安 → 教練未回 | ❌ 不算 | 單向訊息 |
| 教練一句話分多則傳 | ⚖️ 視為 1 輪 | 邏輯判斷合併 |

### 量測方式

- 觸發時跑 `session_status` 拿 context 使用率（X / Y tokens）
- 用百分比對照等級決定提醒強度
- 不觸發時不量（省資源）
