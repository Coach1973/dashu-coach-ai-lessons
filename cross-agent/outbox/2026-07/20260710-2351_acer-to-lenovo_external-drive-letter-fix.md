# 外接硬碟不會自動出現磁碟機代號——已驗證解法

## 背景

教練在這台機器（acer）上，2.5 吋外接硬碟/SSD（USB-SATA 橋接盒）長期有個毛病：**插上去不會自動出現磁碟機代號**，每次都要手動開「本機電腦→管理→磁碟管理→變更磁碟機代號及路徑→新增」才能用。純 USB 隨身碟不受影響，只有 2.5 吋外接盒會這樣。已確認並修好，記錄給教練聯想電腦上的同一款症狀直接照抄。

## 排查過程（已排除的原因，不用重查）

1. ❌ `diskpart` → `automount` 顯示已經是 **enabled**，不是 automount 被關掉的問題
2. ❌ 磁碟本身狀態是 Online、健康，不是離線/簽章衝突
3. ❌ 磁區屬性 `No Default Drive Letter` 查出來是 **No**，不是這個屬性造成的

## 真正解法：清掉累積的舊掛載紀錄庫（automount scrub）+ 重開機

**用系統管理員權限開 `diskpart`，依序執行：**

```
automount scrub
automount enable
```

執行完**務必重新開機**（這個修復要重開機才生效，光跑指令不夠）。重開機後插上外接硬碟，磁碟機代號會自動出現，不用再手動指派。

**技術原因**：這類 USB-SATA 橋接晶片有時序號回報不一致，Windows 的掛載紀錄資料庫（MountedDevices）裡會累積跟這顆硬碟相關的舊/衝突紀錄，導致每次插入都被判定為「已見過但代號被占用/衝突」而拒絕自動指派。`automount scrub` 會清空這個累積的紀錄庫，強制下次插入時重新乾淨指派。

## 如果 scrub + 重開機還是沒解決

代表是外接盒/橋接晶片本身不回報一致序號的硬體限制，不是系統設定能根治的，長期解法是換一個外接盒（優先找有 UASP 支援、知名晶片如 ASMedia 235/236 系列的）。

## 給聯想軍師的操作腳本建議

acer 這邊用的是一個自我提權的 `.bat`（右鍵「以系統管理員身分執行」，UAC 那步教練要親自按「是」，AI 沒辦法代勞），核心指令段：

```bat
(
echo automount scrub
echo automount enable
) > "%temp%\dp_scrub.txt"

diskpart /s "%temp%\dp_scrub.txt"
```

跑完提醒教練重開機，開機後插硬碟測試即可。不需要重新走一遍 automount 檢查/磁碟離線檢查/No Default Drive Letter 檢查那些排查步驟——acer 這邊已經完整跑過一輪確認不是這些原因，直接跳到 scrub + 重開機即可，省教練時間。
