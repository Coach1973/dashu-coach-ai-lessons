# 聯想筆電｜軟體增量資料搬移到外接碟測試紀錄

> 整理日期：2026-07-01
> 來源：聯想筆電（Windows 11）2026-06-25 ~ 06-30 實測
> 用途：給 ACER 筆電參考，規劃同樣的搬移方案
> 整理者：聯想軍師 Opus 4.6

---

## 一、為什麼要搬

這台聯想筆電有「一鍵還原」功能，執行後 C 碟會清空回原廠。
為了保護平時使用軟體產生的資料（聊天記錄、瀏覽紀錄、帳號設定等），
把這些資料搬到 E 碟（外接硬碟），用 Windows 的「junction」讓軟體感覺不到差異。

**junction 是什麼？**
就像一個「路標」——軟體去 C 碟找資料，路標把它轉到 E 碟，軟體完全不知道資料其實不在 C 碟了。

## 三、每個軟體的詳細紀錄

### 1. LINE 桌面版 ✅（最複雜，有血淚教訓）

**搬法：bin 留 C 碟，Data + Cache 用 junction 搬到 E 碟**

為什麼不能整個搬？因為 LINE 新版（26.x）的啟動程式會檢查自己在哪裡啟動的。
如果整個 junction 搬走，啟動程式發現路徑不對，就會報錯「Invalid launcher path」。

| 項目 | 位置 | 大小 |
|------|------|------|
| bin（程式本體） | C 碟原位不動 | 377 MB |
| Data（聊天記錄等） | E:\Claude-Data\LINE-Data | 1,724 MB |
| Cache（暫存圖片等） | E:\Claude-Data\LINE-Cache | 2,263 MB |

**步驟：**
1. 關閉 LINE
2. 用 `robocopy` 把 Data 和 Cache 複製到 E 碟
3. 確認複製完整（檔案數和大小要一致）
4. 把 C 碟原始的 Data、Cache 改名加 `.bak`（當備份，保留 7 天）
5. 建 junction 指向 E 碟
6. 開 LINE 確認聊天記錄都在

**ACER 注意：**
- ACER 的 LINE 版本如果是 9.x（舊版），可以整個資料夾直接 junction，不需要拆
- 如果是 26.x（新版），就要照聯想的做法拆成 bin 留 C + Data/Cache 搬走
- 先查你的 LINE 版本再決定用哪種方式

**🔴 血淚教訓：**
聯想曾經因為搬 LINE 失敗後重裝，過程中 AI 把備份刪了，4GB 聊天記錄永久丟失。
**搬之前一定要先備份，備份至少保留 7 天絕對不刪！**

### 2. Signal ✅（最簡單）

**搬法：整個 AppData\Roaming\Signal 資料夾 junction 搬到 E 碟**

| 項目 | 位置 | 大小 |
|------|------|------|
| Signal 全部資料 | E:\Claude-Data\AppData\Signal | 809 MB |

**步驟：**
1. 關閉 Signal
2. 把 `C:\Users\<用戶>\AppData\Roaming\Signal` 整個複製到 E 碟
3. 確認複製完整
4. C 碟原資料夾改名 `.bak`
5. 建 junction 指向 E 碟
6. 開 Signal 確認正常

Signal 沒有路徑驗證問題，整個搬就好，最簡單。

---

### 3. Zoom ⚠️（搬完要重裝）

**搬法：整個 AppData\Roaming\Zoom 資料夾 junction 搬到 E 碟**

| 項目 | 位置 | 大小 |
|------|------|------|
| Zoom 全部資料 | E:\Claude-Data\AppData\Zoom | 1,200 MB |

**已知問題：**
Zoom 搬到外碟後，從瀏覽器點 Zoom 會議連結時可能偵測不到已安裝。
**解法：搬完之後去 zoom.us 官網重新下載安裝一次就好。**
不要花時間診斷，直接重裝最快。

---

### 4. Chrome 瀏覽器（備份已做，junction 未啟用）

E 碟已有 Chrome 完整備份（User Data 約 6 GB），但目前 C 碟仍是正常資料夾，沒有啟用 junction。

Chrome 的 User Data 包含：
- 瀏覽記錄、書籤、密碼、擴充功能設定、已登入的網站等
- C 碟目前約 5.2 GB

**ACER 如果要搬 Chrome：**
整個 User Data 可以 junction。Chrome 沒有像 LINE 那樣的路徑驗證。
但體積大（5 GB 以上），搬的時候要確認外接碟夠快，否則瀏覽會變慢。

## 四、ACER 規劃建議

### 第一步：先確認要搬哪些軟體
看你的 C 碟空間壓力再決定。優先搬佔空間大的。

### 第二步：確認外接碟的位置
ACER 的工作目錄是 `D:\Claude-Data`，所以搬移目標是 D 碟。

### 第三步：一次只搬一個軟體
搬完一個 → 開軟體確認正常 → 再搬下一個。
**千萬不要一次搬好幾個**，出問題會搞不清楚是哪個壞的。

### 第四步：搬移固定流程（每個軟體都一樣）
1. **備份**：複製到 D 碟
2. **驗證**：確認檔案數和大小一致
3. **改名**：C 碟原資料夾加 `.bak`
4. **建 junction**：`mklink /J` 指向 D 碟
5. **測試**：開軟體確認正常
6. **保留備份 7 天**：`.bak` 資料夾 7 天後才能刪

## 五、一鍵還原後的重建

聯想已經寫好一鍵還原腳本 `restore_junctions.ps1`。
一鍵還原後，用系統管理員身分跑這個腳本，就能把所有 junction 重建回來。

**ACER 也應該寫一份自己的還原腳本**，內容就是把所有 junction 重建。

## 六、鐵律（聯想付出的學費換來的）

| 編號 | 鐵律 | 原因 |
|------|------|------|
| 🔴1 | 備份至少保留 7 天不刪 | 聯想 4GB LINE 資料永久丟失的血淚 |
| 🔴2 | 搬之前先備份，確認備份完整 | 搬壞了還有得救 |
| 🔴3 | 一次只搬一個軟體 | 出問題好查 |
| 🔴4 | 搬完立刻開軟體測試 | 不測就不知道有沒有壞 |
| 🔴5 | LINE 新版（26.x）不能整個搬 | 啟動程式會驗路徑 |
| 🔴6 | Zoom 搬完要重裝 | 瀏覽器偵測會失效 |
| 🔴7 | 搬完要寫還原腳本 | 一鍵還原後能一鍵重建 junction |

## 附錄：Junction 指令範例

```
rem 以系統管理員身分執行 cmd

rem 假設要把 Signal 搬到 D 碟：
rem 1. 先把原資料夾複製到 D:\Claude-Data\Signal
rem 2. 改名原資料夾
ren "C:\Users\<用戶>\AppData\Roaming\Signal" "Signal.bak.20260701"
rem 3. 建 junction
mklink /J "C:\Users\<用戶>\AppData\Roaming\Signal" "D:\Claude-Data\Signal"
```
