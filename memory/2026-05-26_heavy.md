## 為什麼出現「⑭」這種亂碼？

這是 **Unicode 顯示問題**，具體來說是：

### 原因：字元編碼錯誤

當我讀取檔案時，系統在某些情況下會把 **控制字元或不可見字元** 渲染成圓圈數字（①②③...⑮），這些其實是 Unicode 的「Dingbat 負數字」區段（U+2776-U+277F）。

### 可能發生的情境：

| 情況 | 說明 |
|------|------|
| **檔案含有隱藏控制字元** | 某些編輯器或複製貼上時帶入不可見字元 |
| **終端機/顯示器編碼不匹配** | UTF-8 與其他編碼混用 |
| **檔案損壞或格式錯誤** | 二進位內容被當文字讀取 |
