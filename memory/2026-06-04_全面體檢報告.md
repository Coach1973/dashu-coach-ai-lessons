#### 🔴 致命問題 #1：memsearch plugin 設定錯誤

**症狀**：`memory_search` 工具無法使用

**實測錯誤訊息**：
```
Unknown memory embedding provider: memsearch
Memory search is unavailable due to an embedding/provider error.
```

**根因**：
- `openclaw.json` 中 `agents.defaults.memorySearch.provider = "memsearch"`
- 但 memsearch plugin 的 `configSchema` 支援的 provider 是：
  `onnx, openai, google, voyage, jina, mistral, ollama`
- **沒有 `memsearch` 這個 provider**

**影響範圍**：
- `memory_search` 工具完全壞掉（剛剛實測確認）
- 所有依賴記憶搜尋的功能都失效
- 這也解釋了為什麼教練之前的記錄（`memory/reference_openclaw_2026-05-28_upgrade.md`）說「memory_search 不受影響 ✅」是**錯的**

**修正方案**（教練裁決後執行）：
```json
// 把 openclaw.json 中的：
"provider": "memsearch"
// 改成：
"provider": "onnx"      // 推薦，免 API key，本地運算
// 或：
"provider": "google"    // 用 Gemini embedding
```
改完後執行 `openclaw gateway restart`
