## 🎯 為什麼這個群組學弟不說話

### 設計原則：**單一窗口，學長代理**

| 角色 | 在分工群的行為 | 原因 |
|------|--------------|------|
| 🦞 **學長**（1號機） | 唯一公開發言人 | 統籌 + 對教練單一窗口 |
| 🦐 **學弟**（2號機） | 靜默，只在被 @ 時說「✅ 學弟回報：」 | 執行者，不搶話 |
| 🐰 **學妹**（3號機） | 靜默，規則同上 | 同上 |

**為什麼這樣設計：**
1. **避免三機搶話** — 三隻都回會變成菜市場
2. **單一回應** — 教練只要看一隻的回覆，不用對答案
3. **避免重複浪費** — 同一個問題三隻都搶答 = 三倍 Token、三倍 context
4. **責任清楚** — 學長拍板，學弟執行，誰說話誰負責
5. **避開搶 context** — 三隻同時搶 context 會打架
