## 🔍 方法論說明

赫茲米版本的統計方式：**關鍵字全文搜尋**，缺點是同一句話含多個關鍵字會被重複計算，且不區分「系統訊息」和「教練本人說的話」。

**軍師版本（本版）的統計方式：**
1. 先過濾噪音：去掉 `<local-command>`、系統提示語、空白訊息
2. 只取 user 類型（`entry['type'] == 'user'`）的真實訊息內容
3. 內容取自 `entry['message']['content']`
4. 同一則訊息對同一類別痛點只計 1 筆（去重）
5. 每個痛點類別最多保留 3 筆代表內容

> 守則 03（思考就是問問題）：自己動手驗證資料，而不是照單全收別人給的數字。
> 守則 14（提煉是一種美德）：只統計獨立敘述，不做灌水計數。
> 守則 15（說「不知道」比胡說八道更值得尊重）：本版 model 欄位未驗證，聲明「未驗證」而非推估亂填。
