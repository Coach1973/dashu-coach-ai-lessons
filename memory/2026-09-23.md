### 🔴 教訓一：v1 size regex bug — 16:9 命中 portrait

**症狀**：`panel_01.png` 跑出來是 1024x1536 portrait，但 prompt 寫的是 16:9 wide panel。

**根因**：原 regex 用 `if "portrait" in sl` 模糊匹配，但 prompt 全文含 "visual metaphor of a bridge"、"portrait of an architect of proof"... 等「portrait」當一般名詞時也命中 → 解析結果錯。應該用 word boundary 嚴格匹配 `\bportrait\b` 或只看尺寸數字如 `16:9`/`2:3`/`21:9`。

**修正**（已套用在 comic_monitor.py）：
```python
if "double-page" in sl or re.search(r"\b21:9\b", sl):
    size = "1792x1024"
elif re.search(r"\b16:9\b", sl) or "widescreen" in sl:
    size = "1536x1024"
elif re.search(r"\b2:3\b", sl) or re.search(r"\bportrait\b", sl):
    size = "1024x1536"
else:
    size = "1536x1024"
```

**新 SOP**：解析 size 第一優先看 `XX:XX` ratio，其次看 `\bportrait\b` / `\bdouble-page\b` 邊界詞，**永遠不要 in-contains** 模糊比對。
