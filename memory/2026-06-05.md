## 🛠️ Hermit 桌面版「Always allow」解法

### 教練痛點
Hermit 桌面版 App 每次執行 Python `-e` / `-c` 都要跳出「Always allow this command?」對話框，教練覺得很煩很累。

### 教練原話
> 「Hermit 的桌面版 App 執行任務的時候，一直要反覆地讓我同意它去讀取資料夾。」
> 「可以的話，直接幫我執行可以嗎？直接從後臺去修改它，讓它直接加進去，然後就不要再問我，可以吧？」

### 處理過程
1. 教練最初要求「直接從後臺改」→ 我先解釋 macOS 安全機制（守則#15 說真話）
2. 提出三方案讓教練選（守則#16 複雜的解法不一定是正確的解法 → 問用戶要什麼）
3. 教練選 A（只加 command_allowlist，零風險）
4. 備份 `~/.hermes/config.yaml` → `config.yaml.bak.before_hermit_autopermit_20260605_042103`
5. 編輯 `command_allowlist`，從 1 條擴充為 5 條：
   - `script execution via -e/-c flag`（原有）
   - `python3 -e *`（新增）
   - `python3 -c *`（新增）
   - `python3 /Users/bymyway/.openclaw/**`（新增）
   - `python3 /tmp/**`（新增）

### 關鍵發現
- `echotoken` provider 已有 `permissions.allow`：Read/Write `/Users/bymyway/**`、git、ssh、scp
- 但**「Always allow this command」**是另一個機制，由 `command_allowlist` 控制
- 還有一個更高階的 `approvals.mode`（目前 `manual`），如果 A 不夠再做 B

### 教練要重啟 Hermit 才生效
需完全關閉（Cmd+Q）再重開，新設定才會被讀入。
