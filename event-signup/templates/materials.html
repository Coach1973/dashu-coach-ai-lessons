Google 雲端硬碟操作步驟（單一檔案／整個資料夾都可以）：
  1. 把 PPT / PDF / 圖片上傳到雲端硬碟（單檔或整個資料夾皆可）
  2. 在檔案或資料夾上按右鍵 →「共用」→ 一般存取改成「知道連結的任何人」，權限選「檢視者」
  3. （選填，僅單一檔案適用）點「進階設定」把「檢視者及留言者可以下載、列印及複製」關掉，防止學員下載
  4. 複製分享連結，貼到下面欄位即可——貼整個資料夾的連結 {% if drive_authorized %}會自動用API展開成一筆一筆的個別檔案卡片{% else %}會自動嵌入整個資料夾瀏覽器{% endif %}， 不用一個個貼；貼單一檔案連結就只顯示那一份
