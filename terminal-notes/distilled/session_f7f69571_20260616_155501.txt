## 🔍 一、為什麼學長會跑 YouTube 任務

```json
"name": "YouTube 頻道掃描與評估"
"agentId": "main"          ← 學長
"enabled": false           ← 明明是停用狀態
"schedule": "30 12 * * *"  ← 每天中午 12:30
"delivery.to": "-1003877502911"  ← 頂級特助分工群組
```

**這條 cron 是別場 session 建的「每天中午 12:30 抓 YouTube 新片」任務**，後來被某個人停用（enabled=false）。但 OpenClaw 仍在中午 12:30 觸發它——這是 OpenClaw cron 系統本身的 bug：**enabled=false 沒擋住觸發**。

## 🔍 二、為什麼會推失敗訊息（明明 failureAlert=false）

```json
"failureAlert": false              ← 我 7c76f74 加的，應該擋失敗訊息
"delivery.bestEffort": true        ← 這個 flag 走的是另一條路
```

- `FailoverError: AI service overloaded`
