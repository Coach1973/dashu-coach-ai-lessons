⏺ 教練，這次用 inline style 強制（CSS 原生屬性，無法被覆寫）：
     
  <h3 class="... pr-4" 
      style="display: inline-block; width: max-content; max-width: 100%;">
  
  ┌───────────────────────┬─────────────────────────────────────┐
  │         屬性          │                作用                 │
  ├───────────────────────┼─────────────────────────────────────┤
  │ display: inline-block │ 寬度配合內容（不再佔滿整行）        │
  ├───────────────────────┼─────────────────────────────────────┤
  │ width: max-content    │ 寬度 = 整句話自然寬度（不換行）     │
  ├───────────────────────┼─────────────────────────────────────┤
  │ max-width: 100%       │ 防止超出父容器（窄螢幕時不爆）      │
  ├───────────────────────┼─────────────────────────────────────┤
  │ pr-4                  │ 右側 padding 1 字寬（≈ 1 個中文字） │
  └───────────────────────┴─────────────────────────────────────┘
  
  🔍 為什麼上次 w-fit 沒效果

  我用了 Tailwind class w-fit，理論上會編譯成 width: fit-content。但您的瀏覽器渲染出來還是 block 寬度——可能是 Tailwind 
  purge 沒包含這個 class、或是被其他 CSS 規則覆寫。這是我的疏失。
  
  這次改用 inline style，CSS specificity 最高，任何外部樣式都覆寫不了，保證生效。

  - Mac Chrome/Edge：Cmd + Shift + R
  - Mac Safari：Cmd + Option + R
